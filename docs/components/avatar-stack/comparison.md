# AvatarStack Comparison

## Quick Decision Rule

Use `AvatarStack` when several people need to be represented compactly as one grouped display. Use standalone `Avatar` when only one person is shown.

## `AvatarStack` vs `Avatar`

Use `AvatarStack` when:

- several people or entities should be shown together

Use `Avatar` when:

- one person or entity is enough

## `AvatarStack` vs list of names

Use `AvatarStack` when:

- compact visual recognition matters more than explicit enumeration

Use a text list when:

- explicit names, roles, or ordering matter more than compactness

## Choose This Component When

- several people should be represented in a small space
- visual grouping matters more than explicit enumeration
- the stack is acting as a compact group signal rather than a full roster

## Do Not Choose This Component When

- one person is enough
- the UI needs fully explicit names or roles instead of compact avatars
