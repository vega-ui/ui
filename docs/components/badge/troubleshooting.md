# Badge Troubleshooting

## Badge Text Feels Too Long

### Symptom

The badge becomes hard to scan or visually awkward.

### Likely Cause

The content is too long for a compact metadata label.

### How To Verify

- Check whether the text can be understood in one quick glance.
- Compare it with nearby headings or body copy.

### Fix

- Shorten the label.
- Move the explanation into surrounding text if needed.

## Badge Is Carrying Too Much Semantic Weight

### Symptom

Users miss important meaning because the only signal is a tiny colored badge.

### Likely Cause

The product relies on the badge alone to communicate status.

### How To Verify

- Hide the badge and check whether the state is still understandable.

### Fix

- Add surrounding copy, headings, or structure that explains the status.
