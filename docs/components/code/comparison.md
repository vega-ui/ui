# Code Comparison

## Quick Decision Rule

Use `Code` for inline commands, identifiers, and tokens. Use `Text` for prose and a dedicated code block solution for larger snippets.

## `Code` vs `Text`

- Use `Code` for inline code semantics.
- Use `Text` for prose.

## `Code` vs `Badge`

- Use `Code` for code-like identifiers or commands.
- Use `Badge` for status and categorization.

## `Code` vs fenced code blocks

- Use `Code` for short inline fragments.
- Use fenced markdown or a dedicated block component for multiline examples.

## Choose This Component When

- the content is a short code token, command, or identifier
- semantic `<code>` matters

## Do Not Choose This Component When

- the content is a paragraph
- the snippet is multiline or needs syntax highlighting
