# Heading Comparison

## Quick Decision Rule

Use `Heading` when the text defines document or section structure. Use `Text` for prose and `Label` for form fields.

## `Heading` vs `Text`

- Use `Heading` for navigable section structure.
- Use `Text` for body copy.

## `Heading` vs `Label`

- Use `Heading` for sections or pages.
- Use `Label` for one control.

## `Heading` vs `FieldsetLegend`

- Use `Heading` for document structure.
- Use `FieldsetLegend` for native form group labeling.

## Choose This Component When

- the content should appear in the page or section outline
- visual size and semantic level need to stay independent

## Do Not Choose This Component When

- the text labels a form field
- the content is just descriptive copy
