# Separator Comparison

## Quick Decision Rule

Use `Separator` for lightweight visual division. Use `Heading` or `Fieldset` when the UI needs named structure rather than only a line.

## `Separator` vs `Fieldset`

- Use `Separator` for visual division.
- Use `Fieldset` for grouped form semantics.

## `Separator` vs `Heading`

- Use `Separator` when no visible title is needed.
- Use `Heading` when the section needs a semantic label.

## `Separator` vs `Card`

- Use `Separator` inside an existing layout.
- Use `Card` when the whole section needs its own surface.

## Choose This Component When

- two adjacent regions need a subtle divider
- semantic grouping is already handled elsewhere

## Do Not Choose This Component When

- a section needs a label
- a set of controls needs native group semantics
