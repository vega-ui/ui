# Text Comparison

## Quick Decision Rule

Use `Text` for body copy, helper text, and descriptive content. Use `Heading`, `Label`, or `Code` when the content has a more specific semantic role.

## `Text` vs `Heading`

- Use `Text` for paragraphs and supporting copy.
- Use `Heading` for document structure.

## `Text` vs `Label`

- Use `Text` for general copy.
- Use `Label` when the text names a form control.

## `Text` vs `Code`

- Use `Text` for prose.
- Use `Code` for inline code, tokens, commands, or identifiers.

## Choose This Component When

- you need body typography from the shared scale
- semantic meaning comes from surrounding layout or the rendered child

## Do Not Choose This Component When

- the content is a heading
- the content is a form label
- the content should read as inline code
