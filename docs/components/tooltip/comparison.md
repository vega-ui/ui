# Tooltip Comparison

## Quick Decision Rule

Choose `Tooltip` when the content is brief, supplemental, and non-essential.

## `Tooltip` vs `Popover`

Use `Tooltip` when:

- the content is just a hint or description

Use `Popover` when:

- the content is richer or interactive

## `Tooltip` vs `Dialog`

Use `Tooltip` when:

- the user does not need a modal interaction

Use `Dialog` when:

- the content represents an actual task flow

## Choose This Component When

- the content is a short hint
- the UI should stay non-modal and lightweight

## Do Not Choose This Component When

- the content is required, interactive, or task-oriented
