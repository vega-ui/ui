# Examples

Use this file when a component needs more than the examples kept in `index.md`.

## Structure

Prefer the shared scenario taxonomy:

- `Basic`
- `Controlled/Stateful`
- `Form/Integration`
- `Layout/Overlay`
- `Error`
- `Disabled`
- `Edge`

## Example Format

Each example should include:

1. A short scenario title.
2. A small explanation of when the pattern is appropriate.
3. A realistic snippet that uses actual VegaUI exports.
4. Notes about tradeoffs, accessibility, or integration behavior when needed.

## Guidance

- Do not duplicate trivial snippets already present in `index.md`.
- Favor production-style flows over isolated toy examples.
- Keep examples composable and easy to copy into real product code.
