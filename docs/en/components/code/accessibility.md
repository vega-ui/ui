# Code Accessibility

## Labeling

- `Code` does not label controls or regions.

## Keyboard Behavior

- `Code` has no keyboard behavior.

## Focus Behavior

- `Code` is not focusable unless explicitly composed into a focusable element.

## Screen Reader Semantics

- The component renders semantic `<code>`, which helps communicate inline code or identifiers.

## Form Semantics

- `Code` is suitable for commands, field names, tokens, and identifiers referenced near form content.

## Accessibility Risks

- using inline code styling for non-code content
- relying on color or background alone to distinguish code in dense text
