# YearPicker Comparison

## Quick Decision Rule

Use `YearPicker` when the target value is a year or visible year range. Use `MonthPicker` or `DayPicker` when the selection target is more granular.

## `YearPicker` vs `MonthPicker`

- Use `YearPicker` for years.
- Use `MonthPicker` for months.

## `YearPicker` vs `DayPicker`

- Use `YearPicker` when year-level selection is the goal.
- Use `DayPicker` for actual date selection.

## Choose This Component When

- the product flow needs explicit year picking
- a paged year range is easier to browse than typing

## Do Not Choose This Component When

- the real target is a month or full date
- a higher-level calendar mode switch would be simpler
