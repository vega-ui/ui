# API

Используйте этот файл для компонентов, публичный API которых настолько большой, что `index.md` становится перегруженным.

## Рекомендуемые разделы

## Пропсы корня

Задокументируйте основные пропсы компонента в компактной таблице:

| Проп | Тип | По умолчанию | Обязательный | Примечания |
| --- | --- | --- | --- | --- |

## Дочерние части

Перечислите экспортируемые подкомпоненты и роль каждого из них.

## Типы

Задокументируйте экспортируемые вспомогательные типы, объединения и дженерики, важные для потребителя.

## Модель состояния

Отметьте:

- контролируемые и неконтролируемые пропсы
- семантику колбэков
- форму значения
- интеграцию с формами или оверлеями

## Рекомендации

- Держите таблицу краткой и основанной на исходном коде.
- Не повторяйте каждый внутренний тип.
- Указывайте значения по умолчанию, только если они стабильны и важны для потребителя.
