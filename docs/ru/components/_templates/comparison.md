# ComponentName: сравнение

Используйте этот файл, когда компонент легко спутать с соседними контролами.

## Рекомендуемые разделы

## Быстрое правило выбора

Начните с короткого правила, когда этот компонент — правильный выбор по умолчанию.

## `ComponentName` или `OtherComponent`

Повторите этот раздел для каждого значимого сравнения.

Опишите:

- когда использовать этот компонент
- когда использовать другой компонент
- главный компромисс

## Выбирайте этот компонент, когда

Сведите критерии выбора в одном месте.

## Не выбирайте этот компонент, когда

Сведите ситуации, в которых лучше подходит другой компонент.

## Рекомендации

- Сравнивайте только с близкими альтернативами в дизайн-системе.
- Файл о принятии решения, а не о деталях API.
- Предпочитайте продуктовые компромиссы описаниям внешнего вида.
