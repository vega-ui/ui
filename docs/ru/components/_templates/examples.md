# Примеры

Используйте этот файл, когда компоненту нужно больше примеров, чем помещается в `index.md`.

## Структура

Придерживайтесь общей таксономии сценариев:

- `Basic`
- `Controlled/Stateful`
- `Form/Integration`
- `Layout/Overlay`
- `Error`
- `Disabled`
- `Edge`

## Формат примера

Каждый пример должен содержать:

1. Короткое название сценария.
2. Небольшое пояснение, когда паттерн уместен.
3. Реалистичный фрагмент кода с настоящими экспортами VegaUI.
4. При необходимости — заметки о компромиссах, доступности или поведении интеграции.

## Рекомендации

- Не дублируйте тривиальные фрагменты, которые уже есть в `index.md`.
- Отдавайте предпочтение продакшен-сценариям, а не изолированным игрушечным примерам.
- Делайте примеры композируемыми и удобными для копирования в реальный продуктовый код.
