# AvatarStack: доступность

## Подписи

- Окружающий интерфейс должен объяснять, что представляет группа аватаров: ревьюеров, исполнителей или участников.

## Поведение клавиатуры

- У самого `AvatarStack` нет поведения клавиатуры, если вложенные аватары не интерактивны.

## Поведение фокуса

- Поведение фокуса наследуется от содержимого аватара, если оно интерактивно.

## Семантика для скринридеров

- Задавайте осмысленный `alt` для изображений аватаров, когда это уместно.
- Одних инициалов в запасном варианте может не хватить, чтобы однозначно определить человека.

## Семантика форм

- `AvatarStack` служит только для отображения и не является полем формы.

## Риски доступности

- нет окружающего контекста, объясняющего, кого представляет группа
- неоднозначные инициалы без доступного имени где-либо ещё
