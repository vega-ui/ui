# Badge: доступность

## Подписи

Текст бейджа должен быть коротким и понятным сам по себе. Избегайте сокращений, которые понятны только визуально.

## Поведение клавиатуры

- Бейдж обычно статичен и не нуждается в фокусе.
- Если бейдж становится интерактивным, лучше заменить его более подходящим элементом управления.

## Поведение фокуса

- Неинтерактивные бейджи не должны участвовать в порядке табуляции.

## Семантика для скринридеров

- Текст должен сохранять смысл без учёта цвета.
- Если бейдж передаёт важное состояние, окружающий интерфейс тоже должен объяснять его структурно.

## Семантика в формах

- `Badge` не является элементом формы.

## Риски доступности

- Передача смысла только цветом.
- Злоупотребление сокращениями или непонятными счётчиками.
- Превращение бейджа в интерактивный элемент без изменения семантики.
