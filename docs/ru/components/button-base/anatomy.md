# ButtonBase: анатомия

## Обзор

`ButtonBase` — примитив действия из одной части. Он не экспортирует структурные дочерние части, но может передать своё поведение и стили другому элементу через `asChild`.

## Обязательные части

- `ButtonBase`: корневой интерактивный элемент, который отвечает за стили, кольцо фокуса, поведение в отключённом состоянии и data-атрибуты

## Необязательные части

- дочерний элемент в слоте через `asChild`: используйте, когда итоговым семантическим элементом должна быть ссылка или примитив роутера, а не нативный `button`

## Порядок композиции

1. `ButtonBase`
2. необязательный дочерний элемент, когда включён `asChild`

## Допустимые варианты композиции

- нативная кнопка для действий, отправки и сброса формы
- `asChild` с одной ссылкой или ссылкой роутера, когда действие должно выполнять навигацию
- только текст, только иконка или смешанное содержимое — при условии, что итоговое доступное имя понятно

## Недопустимые варианты композиции

- несколько прямых дочерних элементов, когда вы рассчитываете на одну семантическую цель в слоте
- `asChild` с дочерним элементом, который не принимает пробрасываемые пропсы
- использование `ButtonBase` как готовой продуктовой кнопки, когда `Button` или `IconButton` дают более понятный публичный API
