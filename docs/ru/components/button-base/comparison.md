# ButtonBase: сравнение

## Быстрое правило выбора

Выбирайте `ButtonBase`, только когда продукту нужен самый низкоуровневый общий примитив действия. Для обычных продуктовых кнопок предпочитайте `Button` или `IconButton`.

## `ButtonBase` или `Button`

Используйте `ButtonBase`, когда нужны базовые стили действия с собственной структурой.

Используйте `Button`, когда продуктовый код должен описывать стандартную текстовую кнопку через более высокоуровневый публичный API.

## `ButtonBase` или `IconButton`

Используйте `ButtonBase`, когда раскладка с одной иконкой нестандартная или иконка не главное.

Используйте `IconButton`, когда действие в первую очередь выражено иконкой и должно следовать контракту размеров кнопки-иконки.

## `ButtonBase` или `Link`

Используйте `ButtonBase`, когда взаимодействие — это действие.

Используйте `Link`, когда взаимодействие — это навигация и нужно сохранить семантику ссылки.

## Выбирайте этот компонент, когда

- собственному компоненту действия всё равно нужны стили кнопок VegaUI
- `asChild` необходим для роутера или примитива ссылки
- высокоуровневые API раскладки кнопок только мешали бы

## Не выбирайте этот компонент, когда

- продукту нужна просто стандартная кнопка
- взаимодействие — очевидно текстовая ссылка
- потребителям не стоит разбираться в низкоуровневой семантике и `type`
