# Button: сравнение

## Быстрое правило выбора

Используйте `Button` для явных действий, которые инициирует пользователь.

## `Button` или `Link`

Используйте `Button`, когда:

- действие меняет состояние или отправляет данные

Используйте `Link`, когда:

- взаимодействие в первую очередь ведёт на другую страницу

Главный компромисс: у кнопки семантика действия, у ссылки — семантика навигации.

## `Button` или `IconButton`

Используйте `Button`, когда:

- видимый текст делает действие понятнее

Используйте `IconButton`, когда:

- действие компактное и уже узнаваемо как контрол из одной иконки

Главный компромисс: кнопка понятнее, кнопка-иконка компактнее.

## `Button` или `ButtonBase`

Используйте `Button`, когда:

- продуктовому коду нужна стандартная текстовая поверхность действия

Используйте `ButtonBase`, когда:

- для кастомной композиции нужен низкоуровневый примитив действия

## Выбирайте этот компонент, когда

- Основная задача — действие, а не навигация.
- Видимый текст помогает понять действие.
- Интерфейсу подходит стандартная поверхность кнопки.
- компонент должен быть выбором по умолчанию для действия, а не низкоуровневым примитивом

## Не выбирайте этот компонент, когда

- Основная задача — навигация.
- Действие обозначено только иконкой и места мало.
- На самом деле это текстовая ссылка в основном тексте.
