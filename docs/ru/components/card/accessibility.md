# Card: доступность

## Подпись

Сам `Card` не является подписываемым элементом управления. Значимые подписи принадлежат заголовкам, тексту, ссылкам или действиям внутри него.

## Поведение клавиатуры

- Статичной карточке обычно не нужен фокус.
- Если карточка становится интерактивной через `asChild`, отрендеренный дочерний элемент должен сохранять корректную семантику.

## Поведение фокуса

- Неинтерактивные карточки не должны попадать в порядок табуляции.
- Интерактивные композиции карточки должны давать понятное оформление фокуса на отрендеренном интерактивном корне.

## Семантика для скринридеров

- Поверхность карточки не должна заменять настоящие заголовки или ориентиры (landmarks).
- Сгруппированному содержимому всё равно нужна осмысленная внутренняя структура.

## Семантика форм

- `Card` — не элемент управления формы.
- Семантика формы принадлежит полям внутри карточки.

## Риски доступности

- Замена информационной иерархии оформлением поверхности.
- Кликабельная карточка без понятного интерактивного корня.
- Прозрачные карточки там, где сгруппированное содержимое теряет отделение от фона.
