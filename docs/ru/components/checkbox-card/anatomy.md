# CheckboxCard: анатомия

## Обзор

`CheckboxCard` — составная карточка выбора. Корень рендерит подписанную поверхность карточки, а экспортируемые дочерние части разделяют содержимое, заголовок, описание и UI контрола.

## Обязательные части

- `CheckboxCard`: корневая подписанная карточка и общий контекст чекбокса
- `CheckboxCardContent`: колонка содержимого для основного текста
- `CheckboxCardControl`: область контрола для чекбокса
- `CheckboxCardControlInput`: нативный чекбокс внутри контрола
- `CheckboxIndicator` (из `Checkbox`): видимый квадрат внутри контрола

## Необязательные части

- `CheckboxCardTitle`
- `CheckboxCardDescription`
- `CheckboxCardControlCheckedIcon`
- `CheckboxCardControlIndeterminateIcon`

## Порядок композиции

1. `CheckboxCard`
2. `CheckboxCardContent`
3. `CheckboxCardTitle` и `CheckboxCardDescription`
4. `CheckboxCardControl`
5. `CheckboxCardControlInput` и `CheckboxIndicator` с иконками состояний внутри контрола

## Допустимые варианты композиции

- плитки тарифов, где вся карточка служит подписью чекбокса
- карточки настроек с коротким заголовком и поясняющим описанием
- горизонтальная или вертикальная раскладка в зависимости от плотности

## Недопустимые варианты композиции

- кликабелен только контрол, а окружающая подпись или карточка — нет
- карточки-чекбоксы используются для взаимоисключающего выбора одного варианта
- декоративное содержимое заслоняет фактическое отмеченное состояние
