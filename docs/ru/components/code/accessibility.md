# Code: доступность

## Подписи

- `Code` не служит подписью для контролов или областей.

## Поведение клавиатуры

- У `Code` нет клавиатурного поведения.

## Поведение фокуса

- `Code` не получает фокус, если только его явно не поместили внутрь фокусируемого элемента.

## Семантика для скринридеров

- Компонент рендерит семантический `<code>`, который помогает передать встроенный код или идентификаторы.

## Семантика форм

- `Code` подходит для команд, имён полей, токенов и идентификаторов, упоминаемых рядом с содержимым формы.

## Риски доступности

- оформление встроенного кода для содержимого, которое кодом не является
- различение кода в плотном тексте только по цвету или фону
