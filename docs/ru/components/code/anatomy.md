# Code: анатомия

## Обзор

`Code` — примитив из одной части. Он рендерит семантический `<code>` и применяет оформление встроенного кода VegaUI.

## Обязательные части

### `Code`

Обязательная. Отвечает и за семантический элемент, и за оформление встроенной плашки.

## Необязательные части

Экспортируемых дочерних частей нет.

## Порядок композиции

1. `Code`
2. содержимое встроенного кода

## Корректные паттерны композиции

`Code` стоит внутри абзаца `Text` и оборачивает только машиночитаемые фрагменты.

<!-- example: code/basic-usage.tsx -->
```tsx
import { Code, Text } from '@vega-ui/react';

export default function BasicUsage() {
  return (
    <Text asChild size={3}>
      <p>
        Run <Code>pnpm dev</Code> and open <Code>localhost:3000</Code> in your browser.
      </p>
    </Text>
  );
}
```
<!-- /example -->

## Некорректные паттерны композиции

### Большие фрагменты кода внутри строки

Длинные команды или фрагменты становится трудно читать.

### `Code` как универсальная выделенная метка

Компонент должен сохранять семантику кода.
