# Code: сравнение

## Быстрое правило выбора

Используйте `Code` для встроенных команд, идентификаторов и токенов. Для обычного текста используйте `Text`, а для больших фрагментов — отдельное решение для блоков кода.

## `Code` или `Text`

- Используйте `Code` для семантики встроенного кода.
- Используйте `Text` для обычного текста.

## `Code` или `Badge`

- Используйте `Code` для идентификаторов и команд, похожих на код.
- Используйте `Badge` для статусов и категорий.

## `Code` или блоки кода в markdown

- Используйте `Code` для коротких встроенных фрагментов.
- Для многострочных примеров используйте блоки кода в markdown или отдельный компонент блока.

## Выбирайте этот компонент, когда

- содержимое — короткий токен кода, команда или идентификатор
- важна семантика `<code>`

## Не выбирайте этот компонент, когда

- содержимое — абзац текста
- фрагмент многострочный или требует подсветки синтаксиса
