# Code

## Профиль документа

`primitive`

## Кратко

`Code` — примитив встроенного кода. Он использует контракт `Text` и рендерит семантический `<code>` на приглушённой встроенной подложке.

## Импорт

```tsx
import { Code, type CodeProps } from '@vega-ui/react';
```

## Экспортируемые типы

- `CodeProps`

## Базовое использование

<!-- example: code/basic-usage.tsx -->
```tsx
import { Code, Text } from '@vega-ui/react';

export default function BasicUsage() {
  return (
    <Text asChild size={3}>
      <p>
        Run <Code>pnpm dev</Code> and open <Code>localhost:3000</Code> in your browser.
      </p>
    </Text>
  );
}
```
<!-- /example -->

## Варианты

- Типографика: наследует размеры `Text`
- Композиция: семантический встроенный элемент `<code>`
- Оформление: плашка кода с `inline-block` на приглушённой подложке

## Пограничные случаи

- Длинные значения могут переноситься, потому что компонент разрешает `word-wrap: break-word`.
- `Code` рассчитан на встроенные фрагменты, а не на большие блоки кода.
- Он наследует пропсы `Text`, поэтому изменение размера влияет и на пропорции плашки.

## Типичные ошибки

- `Code` для многострочных блоков документации.
- Оформление кода для обычных меток или бейджей.
- Жёстко заданные цвета вместо токенов темы, управляющих контрастом.
