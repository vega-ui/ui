# Collapsible: сравнение

## Быстрое правило выбора

Используйте `Collapsible`, когда достаточно одного отдельного раскрывающегося раздела.

## `Collapsible` или `Accordion`

Используйте `Collapsible`, когда:

- функции нужен один раскрывающийся блок
- координация общего состояния между разделами не нужна

Используйте `Accordion`, когда:

- несколько связанных разделов должны использовать одну модель состояния открытия

Главный компромисс: `Collapsible` легче и проще, а `Accordion` даёт согласованное групповое раскрытие.

## `Collapsible` или `Popover`

Используйте `Collapsible`, когда:

- содержимое должно оставаться встроенным в поток страницы

Используйте `Popover`, когда:

- содержимое должно всплывать рядом с триггером

Главный компромисс: `Collapsible` сохраняет непрерывность раскладки, а `Popover` даёт более сильное локальное отделение.

## Выбирайте этот компонент, когда

- Достаточно одного раскрывающегося раздела.
- Содержимое должно оставаться встроенным.
- Функции нужна только простая модель раскрытия «триггер — содержимое».

## Не выбирайте этот компонент, когда

- Несколько разделов должны координироваться.
- Содержимое должно вести себя как всплывающий оверлей.
- Функции нужно модальное поведение или групповая навигация.
