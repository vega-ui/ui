# Collapsible: стилизация

## Обзор

У `Collapsible` небольшой контракт стилизации, построенный вокруг переходов высоты содержимого. Сам корень не предоставляет большого набора переменных, поэтому большая часть темизации делается через триггер и окружающую раскладку.

## Публичные CSS-переменные

| Переменная | Где используется | Назначение |
| --- | --- | --- |
| `--transition-state-delay` | `CollapsibleContent` | Длительность анимации высоты. |

## Переменные уровня частей

- `Collapsible`: владелец состояния корня без отдельного модуля стилей.
- `CollapsibleTrigger`: стили берутся из отрендеренного элемента триггера или поверхности `asChild`.
- `CollapsibleContent`: владеет переходом высоты, обрезкой переполнения и поведением скрытого состояния.

## Взаимодействие состояний и вариантов

- Состояния открытия и скрытия связаны, но во время переходов не совпадают.
- При композиции через `asChild` видимый стиль триггера часто приходит из другого компонента, например `Button`.
- У открытого содержимого `height: auto`, поэтому содержимое, которое растёт или уменьшается после открытия, включая вложенные `Collapsible`, не требует дополнительной работы.

## Примеры

<!-- example: collapsible/examples.css -->
```css
.slowCollapsible {
  --transition-state-delay: 220ms;
}
```
<!-- /example -->

<!-- example: collapsible/styling-examples.css -->
```css
.compactDisclosureButton {
  font-size: 14px;
}
```
<!-- /example -->

## Не переопределяйте

- Не убирайте правила переполнения, если раздел по-прежнему опирается на анимацию высоты.
- Не считайте, что стили триггера принадлежат `Collapsible`, когда используется `asChild`.
