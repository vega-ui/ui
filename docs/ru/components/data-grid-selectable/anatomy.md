# DataGridSelectable: анатомия

## Обзор

`DataGridSelectable` — составная поведенческая сетка. Она добавляет логику выбора и активной ячейки поверх `DataGrid` и экспортирует части группы строк, строки и ячейки для композиции.

## Обязательные части

- `DataGridSelectable`: корневая поведенческая сетка
- `DataGridSelectableRowGroup`: группа строк, при необходимости со своей областью
- `DataGridSelectableRow`: одна строка матрицы
- `DataGridSelectableCell`: одна выбираемая ячейка

## Необязательные части

- `apiRef`: чтение или управление базовой сеткой
- `resolveRange`, `compare`, `equals`: точки настройки продвинутого поведения выбора
- `disabled`, `exclude`, `from`, `to`: ограничения выбора

## Порядок композиции

1. `DataGridSelectable`
2. `DataGridSelectableRowGroup`
3. `DataGridSelectableRow`
4. `DataGridSelectableCell`

## Допустимые паттерны композиции

- плотные сетки выбора со стабильными ключами строк и столбцов
- ограниченные поддиапазоны через `from` и `to`
- выбор диапазона с собственным резолвером, когда модель ключей не чисто последовательная

## Недопустимые паттерны композиции

- нестабильные ключи ячеек между рендерами
- презентационные дочерние элементы, которые не сохраняют семантику ячейки
- ожидание поведения выбора от `DataGrid` без обёртки selectable
