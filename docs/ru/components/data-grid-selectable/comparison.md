# DataGridSelectable: сравнение

## Быстрое правило выбора

Выбирайте `DataGridSelectable`, когда главное требование — поведение выбора, а внешний вид ячеек собственный. Выбирайте `DataGridPicker`, когда визуальный слой пикера должен быть стандартным.

## `DataGridSelectable` и `DataGrid`

Используйте `DataGridSelectable`, когда ячейки должны выбираться.

Используйте `DataGrid`, когда сетка навигируемая или презентационная, но не построена вокруг выбора.

## `DataGridSelectable` и `DataGridPicker`

Используйте `DataGridSelectable`, когда продукту нужны собственные стили ячеек и прямой контроль над визуальным слоем.

Используйте `DataGridPicker`, когда поверхность выбора в стиле пикера должна приходить из VegaUI.

## Выбирайте этот компонент, когда

- главная задача — диапазон, множественный выбор или собственные правила выбора
- визуальный слой специфичен для приложения
- нужны собственные функции сравнения или вычисления диапазона

## Не выбирайте этот компонент, когда

- интерфейсу нужна просто стандартная сетка пикера
- потребители не должны сами проектировать визуальный слой выбора
- сетка чисто презентационная
