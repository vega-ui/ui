# DataGrid: сравнение

## Быстрое правило выбора

Выбирайте `DataGrid`, когда навигация с клавиатуры между отдельными ячейками — часть основного взаимодействия.

## `DataGrid` или `Table`

Используйте `DataGrid`, когда:

- ячейкам нужно управление активным фокусом
- важно взаимодействие в духе электронной таблицы

Используйте `Table`, когда:

- содержимое в основном статичное
- семантическое чтение таблицы важнее навигации по ячейкам

## `DataGrid` или `DataGridSelectable`

Используйте `DataGrid`, когда:

- достаточно базовой навигации
- выбор должен оставаться вне слоя сетки

Используйте `DataGridSelectable`, когда:

- выбор строк или ячеек — часть UX

## `DataGrid` или `DataGridPicker`

Используйте `DataGrid`, когда:

- главная задача — навигация по сетке

Используйте `DataGridPicker`, когда:

- сетка служит поверхностью выбора значения, а не общей системой навигации по ячейкам

## Выбирайте этот компонент, когда

- перемещение с клавиатуры между ячейками задумано намеренно
- сетка — скорее модель взаимодействия, чем статичная таблица
- производные слои выбора или пикера были бы преждевременны

## Не выбирайте этот компонент, когда

- достаточно семантической `Table`
- пользователю не нужна навигация по активной ячейке
- сценарии выбора лучше реализуют производные семейства сетки
