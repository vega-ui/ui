# DataGrid: решение проблем

## Навигация с клавиатуры работает странно

### Симптом

Активная ячейка перемещается не так, как выглядит видимая сетка.

### Вероятная причина

Режим переноса или правила исключений не совпадают с отрендеренной раскладкой.

### Как проверить

- посмотрите `wrap`
- посмотрите `exclude`
- сравните видимую матрицу с путём навигации с клавиатуры

### Решение

- согласуйте правила исключений с реальными пустыми ячейками
- выберите подходящий для продуктового сценария режим `wrap`

## Активная ячейка не синхронизируется с родителем

### Симптом

Интерфейс вроде бы меняет активную ячейку, но состояние родителя отстаёт или расходится.

### Вероятная причина

Контролируемое активное состояние не опирается на единый источник истины.

### Как проверить

- посмотрите `active`
- посмотрите `onChangeActive`

### Решение

- храните `active` в одном источнике состояния у родителя
- передавайте этот же источник в `DataGrid`

## Интерактивное содержимое ячеек ломает работу с клавиатуры

### Симптом

Кнопки или кастомные виджеты внутри ячейки мешают навигации по сетке.

### Вероятная причина

Содержимое ячейки конкурирует с собственной моделью фокуса сетки.

### Как проверить

- перейдите в сетку по Tab
- перемещайтесь с клавиатуры
- проверьте взаимодействие с содержимым ячейки

### Решение

- сначала упростите содержимое ячейки
- возвращайте интерактивные контролы, только если модель клавиатуры по-прежнему работает
