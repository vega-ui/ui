# DayPicker: сравнение

## Быстрое правило выбора

Используйте `DayPicker`, когда нужно низкоуровневое поведение выбора в сетке дней. Используйте `Calendar`, когда нужен календарь более высокого уровня.

## `DayPicker` или `Calendar`

- Используйте `DayPicker` для низкоуровневой композиции сетки дней.
- Используйте `Calendar` для календарной подсистемы более высокого уровня.

## `DayPicker` или `MonthPicker` / `YearPicker`

- Используйте `DayPicker` для конкретных дат.
- Используйте `MonthPicker` или `YearPicker` для выбора месяца или года.

## Выбирайте этот компонент, когда

- вы расширяете внутренности семейства календарей
- нужен выбор в сетке дней с собственной композицией

## Не выбирайте этот компонент, когда

- нужна календарная абстракция более высокого уровня с меньшим объёмом ручной композиции
