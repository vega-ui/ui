# Fieldset: доступность

## Подписи

- `FieldsetLegend` должен давать основное доступное имя группы.
- `FieldsetHeader` — вспомогательный текст, а не замена legend.

## Поведение клавиатуры

- `Fieldset` не задаёт собственного поведения клавиатуры.
- Взаимодействие с клавиатуры обеспечивают элементы управления внутри группы.

## Поведение фокуса

- Фокус переходит сразу на вложенные элементы управления, а не на сам контейнер fieldset.
- Нативный `disabled` на корне запрещает взаимодействие с вложенными элементами формы.

## Семантика для скринридеров

- Корень использует нативную семантику `<fieldset>`.
- `FieldsetLegend` соответствует нативному `<legend>`, по которому скринридеры объявляют подпись группы.

## Семантика в формах

- Используйте `Fieldset`, когда несколько связанных полей должны восприниматься как один раздел формы.
- При валидации на уровне группы оставляйте legend неизменной и добавляйте текст ошибки отдельно.

## Риски доступности

- отсутствие `FieldsetLegend`
- визуальные заголовки вне fieldset как единственная подпись группы
- вложение нескольких групп без понятной иерархии legend
