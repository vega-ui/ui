# Grid: анатомия

## Обзор

`Grid` отвечает за модель активной ячейки, поведение переноса, логику исключений и навигацию с клавиатуры по строкам и ячейкам.

## Обязательные части

### `Grid`

Корневой провайдер, координирующий активную ячейку.

### `GridRowGroup`

Группирующий контейнер для строк.

### `GridRow`

Единица регистрации строки.

### `GridCell`

Единица регистрации ячейки и навигации.

## Необязательные части

### Контролируемое состояние активной ячейки

Для более сложных продуктовых сценариев активной ячейкой может владеть родитель.

### `GridColumnHeader` и `GridRowHeader`

Ячейки-заголовки с `role="columnheader"` и `role="rowheader"`, которые ставятся в `GridRow` с `col`, как ячейки. Они участвуют в навигации с клавиатуры, поэтому кнопка сортировки в заголовке достижима, и никогда не выбираются. Передайте `excluded` заголовку, с которым нечего делать, например названию дня недели.

### Интерактивное содержимое ячейки

Поля ввода, кнопки и меню внутри ячейки работают по паттерну WAI-ARIA grid: у них `tabIndex={-1}`, а фокус сетки остаётся на ячейке; Enter или F2 переносят фокус на её первый фокусируемый элемент, Tab ходит по кругу внутри ячейки, а Escape возвращает фокус на ячейку. Клавиши, нажатые внутри содержимого, например стрелки в поле ввода, остаются у содержимого. Tab на ячейке выводит из сетки, а не останавливается на каждой кнопке внутри. Ячейка, которая сама является одним виджетом, — это `<GridCell asChild><button /></GridCell>`.

### `asChild`

`Grid`, `GridRowGroup`, `GridRow`, `GridCell` и заголовки отрисовывают свой дочерний элемент вместо `div`, поэтому сетку можно собрать на `table`, `tbody`, `tr`, `th` и `td` с нативной табличной раскладкой.

### `apiRef`

Необязательный императивный мост: `focus(key)` переносит фокус на ячейку, в том числе на ту, что отрисуется позже.

### Выбор

`selection` включает одиночный, множественный или диапазонный выбор: ячейки получают `aria-selected`, а клик, Enter или Space выбирают их. `disabled`, `min` и `max` его ограничивают; `compare` и `resolveRange` подстраивают под модель ключей.

### `GridItem`

Вид ячейки пикера без собственного поведения: `size`, `variant`, выбранное состояние, диапазон от начала до конца и отключённое состояние. Помещайте его внутрь `<GridCell asChild>`, которая даёт ему роль, фокус, `aria-selected`, `aria-disabled` и `data-range`.

### `GridScroller` с `IndexedSnapScrollerContent`

Разбивают сетку на страницы через скроллер с привязкой. Каждая страница — это `IndexedSnapScrollerContent`, она берёт свой `index` из `useIndexedSnapScrollerContext`; когда страница прокручивается в видимую область, а активной ячейки на ней нет, её первая доступная ячейка становится активной.

## Порядок композиции

Типичная композиция:

1. `Grid`
2. `GridRow` с `GridColumnHeader`, когда у столбцов есть заголовки
3. `GridRowGroup`
4. `GridRow`
5. `GridRowHeader`, когда у строк есть заголовки
6. `GridCell`

## Корректные варианты композиции

Дайте сетке доступное имя. `defaultActive` (или контролируемый `active`) задаёт первую точку Tab; без него ею становится первая выбранная ячейка, иначе первая фокусируемая.

<!-- example: grid/minimal-composition.tsx -->
```tsx
import {
  Grid,
  GridCell,
  GridRow,
  GridRowGroup,
} from '@vega-ui/react';
import './examples.css';

export default function MinimalComposition() {
  return (
    <Grid aria-label='Release checklist' defaultActive='0:0' className='gridSheet'>
      <GridRowGroup>
        <GridRow row={0}>
          <GridCell col={0}>Design</GridCell>
          <GridCell col={1}>Build</GridCell>
          <GridCell col={2}>Ship</GridCell>
        </GridRow>
        <GridRow row={1}>
          <GridCell col={0}>Done</GridCell>
          <GridCell col={1}>In progress</GridCell>
          <GridCell col={2}>Not started</GridCell>
        </GridRow>
      </GridRowGroup>
    </Grid>
  );
}
```
<!-- /example -->

## Некорректные варианты композиции

### Ячейки без соответствующей структуры строк или столбцов

Это ломает допущения навигации и расчёт активной ячейки.

### Разреженная раскладка без логики исключений

Модель клавиатуры может по-прежнему пытаться проходить через визуальные пробелы.

### `Grid` как чисто визуальная таблица

`Grid` — система навигации с клавиатуры, а не просто примитив раскладки.

### Строка заголовков с номером строки тела

Заголовки и ячейки с одинаковым `row` сливаются для клавиатуры в одну строку. Нумеруйте строку заголовков отдельно, например `row={-1}`.

### Статичный заголовок без `excluded`

Клавиатура останавливается на заголовке, с которым нечего делать. Передайте `excluded`.

### Нестабильные ключи ячеек при выборе

Выбранные и активные ячейки смещаются, когда ключи меняются между рендерами.
