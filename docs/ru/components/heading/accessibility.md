# Heading: доступность

## Подписи

- Заголовки подписывают разделы содержимого, а не поля формы.

## Поведение клавиатуры

- У `Heading` нет поведения клавиатуры.

## Поведение фокуса

- Сам заголовок не получает фокус, если его явно не собрать с фокусируемым элементом.

## Семантика для скринридеров

- `as` определяет, увидят ли вспомогательные технологии `h1`–`h6`.
- Используйте уровни заголовков, чтобы построить осмысленную структуру документа.

## Семантика форм

- `Heading` может открывать раздел формы, но не заменяет `Label` или `FieldsetLegend`.

## Риски доступности

- выбор уровня заголовка по визуальному размеру, а не по иерархии
- пропуск уровней без структурной причины
- использование `Heading` там, где нужна подпись или легенда
