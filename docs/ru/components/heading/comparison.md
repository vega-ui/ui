# Heading: сравнение

## Быстрое правило выбора

Используйте `Heading`, когда текст задаёт структуру документа или раздела. Используйте `Text` для основного текста и `Label` для полей формы.

## `Heading` и `Text`

- Используйте `Heading` для навигируемой структуры разделов.
- Используйте `Text` для основного текста.

## `Heading` и `Label`

- Используйте `Heading` для разделов или страниц.
- Используйте `Label` для одного элемента управления.

## `Heading` и `FieldsetLegend`

- Используйте `Heading` для структуры документа.
- Используйте `FieldsetLegend` для подписи нативной группы полей формы.

## Выбирайте этот компонент, когда

- содержимое должно попасть в структуру страницы или раздела
- визуальный размер и семантический уровень должны оставаться независимыми

## Не выбирайте этот компонент, когда

- текст подписывает поле формы
- содержимое — просто описательный текст
