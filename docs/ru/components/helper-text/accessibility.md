# HelperText: доступность

## Подписи

- `HelperText` не заменяет видимый `Label`.

## Поведение клавиатуры

- У `HelperText` нет поведения клавиатуры.

## Поведение фокуса

- По умолчанию `HelperText` не фокусируется.

## Семантика для скринридеров

- Компонент рендерит вспомогательное содержимое в виде абзаца.
- Свяжите его с элементом управления, если ваш паттерн формы опирается на связи через described-by.

## Семантика форм

- Используйте вспомогательный текст для дополнительных подсказок рядом с полем.
- Настоящее невалидное состояние задавайте на самом поле, а не только во вспомогательном тексте.

## Риски доступности

- использование вспомогательного текста вместо подписи
- обозначение ошибки только цветом текста
