# HelperText: решение проблем

## Поле по-прежнему ощущается неподписанным

### Симптом

Поясняющий текст есть, но пользователи всё равно не понимают, для чего поле.

### Вероятная причина

`HelperText` используется без понятной видимой подписи.

### Как проверить

- мысленно скройте вспомогательный текст
- проверьте, остаётся ли одна очевидная подпись

### Решение

Добавьте `Label` или `FieldsetLegend` для основного названия поля.

## Текст ошибки виден, но поле не выглядит невалидным

### Симптом

Текст сообщает об ошибке, но сам элемент управления визуально остаётся обычным.

### Вероятная причина

Задан только `HelperText error`.

### Как проверить

- изучите пропсы поля
- убедитесь, применено ли невалидное состояние к обёртке поля или к input

### Решение

Примените состояние ошибки к полю, а `HelperText` оставьте поясняющим текстом.

## Вспомогательный текст слишком длинный, чтобы его быстро прочитать

### Симптом

Пользователи игнорируют сообщение, потому что оно читается как абзац.

### Вероятная причина

Компонент используется для поясняющего содержимого вместо краткой подсказки.

### Как проверить

- оцените длину сообщения
- проверьте, вписывается ли текст в быстрый просмотр формы

### Решение

Перенесите длинные объяснения в `Text`, справочные материалы или отдельный поясняющий раздел.
