# Icon: доступность

## Подписи

- `Icon` по умолчанию ставит `aria-hidden='true'` — это верно для декоративных иконок.
- Если иконка несёт самостоятельный смысл, дайте доступную подпись через окружающий элемент управления или текст.

## Поведение клавиатуры

- У `Icon` нет поведения клавиатуры.

## Поведение фокуса

- `Icon` по умолчанию не получает фокус.

## Семантика для скринридеров

- Декоративные иконки должны оставаться скрытыми от вспомогательных технологий.
- Значимый статус не должен передаваться только иконками.

## Семантика форм

- `Icon` — презентационный элемент, а не поле формы.

## Риски доступности

- смысл передаётся только иконкой без текста
- предположение, что каждую иконку нужно объявлять
