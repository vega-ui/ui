# Icon: сравнение

## Быстрое правило выбора

Используйте `Icon`, чтобы рендерить SVG с размерами и цветом по правилам VegaUI. Используйте текст или подписи, когда смысл должен быть явным, а не чисто визуальным.

## `Icon` или «голый» SVG

- Используйте `Icon` для единообразных размеров и наследования цвета.
- «Голый» SVG используйте, только если намеренно хотите обойти общий контракт иконок.

## `Icon` или `Avatar`

- Используйте `Icon` для символической графики.
- Используйте `Avatar` для идентификации людей или сущностей.

## Выбирайте этот компонент, когда

- нужен один масштабируемый SVG-глиф
- размер должен следовать токенам иконок VegaUI

## Не выбирайте этот компонент, когда

- интерфейсу нужен полноценный самостоятельный статус с подписью
- содержимое на самом деле не является SVG-иконкой
