# IndexedSnapScroller: сравнение

## Быстрое правило выбора

Используйте `IndexedSnapScroller`, когда пролистывание должно управляться логическим, возможно неограниченным индексом. Используйте `SnapScroller`, когда набор страниц уже стабилен и задан явно.

## `IndexedSnapScroller` или `SnapScroller`

- Используйте `IndexedSnapScroller` для сдвигающихся логических окон.
- Используйте `SnapScroller` для страниц, заданных напрямую с ключами.

## `IndexedSnapScroller` или `DayPickerScroller` / `YearPickerScroller`

- Используйте `IndexedSnapScroller` как низкоуровневый примитив пролистывания по индексам.
- Используйте скроллеры пикеров, когда предметная область — уже календарное пролистывание.

## Выбирайте этот компонент, когда

- содержимое лучше всего описывается виртуальной последовательностью индексов
- окно страниц должно сдвигаться, когда пользователь приближается к границам

## Не выбирайте этот компонент, когда

- достаточно фиксированного набора страниц
- больше подходят обёртки пролистывания, специфичные для календаря
