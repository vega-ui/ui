# Label: доступность

## Подписи

- Используйте `htmlFor`, когда элемент управления рендерится отдельно.
- Для композиций в духе чекбокса допустимо и обернуть элемент управления в `Label`.

## Поведение клавиатуры

- У `Label` нет собственного поведения клавиатуры.
- За взаимодействие с клавиатуры отвечает связанный элемент управления.

## Поведение фокуса

- Клик по подписи должен переводить фокус на связанный элемент управления, если нативная связь подписи не нарушена.

## Семантика для скринридеров

- `Label` рендерит нативный `<label>`.
- При корректной связи вспомогательные технологии используют его как имя связанного поля ввода.

## Семантика форм

- Предпочитайте видимый `Label` тексту плейсхолдера.
- Сохраняйте одну понятную связь подписи с элементом управления.

## Риски доступности

- отсутствие `htmlFor`, когда элемент управления рендерится отдельно
- одна подпись для нескольких несвязанных элементов управления
- ссылки или кнопки внутри подписи без проверки поведения клика
