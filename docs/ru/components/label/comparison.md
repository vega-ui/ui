# Label: сравнение

## Быстрое правило выбора

Используйте `Label` для подписей элементов управления формы. Используйте `Text` или `Heading` для текста, который не является именем поля ввода.

## `Label` или `Text`

Используйте `Label`, когда:

- текст задаёт имя элемента управления формы

Используйте `Text`, когда:

- содержимое — основной текст, вспомогательный текст или статичное содержимое

## `Label` или `Heading`

Используйте `Label`, когда:

- текст задаёт имя одного элемента управления

Используйте `Heading`, когда:

- текст определяет структуру раздела или страницы

## `Label` или `FieldsetLegend`

Используйте `Label`, когда:

- одному полю нужна видимая семантическая подпись

Используйте `FieldsetLegend`, когда:

- группе связанных элементов управления нужна одна общая семантическая подпись

## Выбирайте этот компонент, когда

- одному полю нужна видимая семантическая подпись
- важно нативное поведение клика по подписи
- текст имени должен оставаться тесно связанным с одним элементом управления

## Не выбирайте этот компонент, когда

- содержимое — заголовок или абзац
- нужно подписать целую группу, а не один элемент управления
