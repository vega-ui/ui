# Label

## Профиль документа

`primitive`

## Кратко

`Label` — семантический примитив подписи для полей формы. Он переиспользует типографический контракт `Text`, но рендерит нативный элемент `<label>`, поэтому задание имени элементу управления остаётся отделённым от общих стилей текста.

## Импорт

```tsx
import { Label, type LabelProps } from '@vega-ui/react';
```

## Экспортируемые типы

- `LabelProps`

## Базовое использование

<!-- example: label/field-label.tsx -->
```tsx
import { Label, TextField, TextFieldInput } from '@vega-ui/react';
import { useId } from 'react';

export default function FieldLabel() {
  const id = useId();

  return (
    <div style={{ display: 'grid', gap: 'var(--spacing-3)', width: '100%' }}>
      <Label htmlFor={id}>Company name</Label>
      <TextField>
        <TextFieldInput id={id} name='company' autoComplete='organization' />
      </TextField>
    </div>
  );
}
```
<!-- /example -->

## Варианты

- Размер: следует контракту размеров подписи из `LabelProps`
- Композиция: нативный элемент подписи со стилями текста VegaUI
- Интеграция: прямое использование `htmlFor` или обёртывание элемента управления

## Пограничные случаи

- Одновременно оборачивать элемент управления и использовать `htmlFor` обычно не нужно.
- `Label` наследует типографическую модель `Text`, поэтому визуальные изменения могут нарушить единообразие подписей полей.
- Интерактивное содержимое внутри подписи может сделать поведение клика неоднозначным.
- `Label` должен задавать имя одному элементу управления или одному обёрнутому полю ввода; подписи групп — задача `FieldsetLegend`.

## Частые ошибки

- Использовать текст плейсхолдера как единственную видимую подпись.
- Использовать `Label` для статичных заголовков разделов вместо подписей элементов управления формы.
- Помещать несколько несвязанных элементов управления в одну подпись-обёртку.
