# Link: доступность

## Подписи

Текст ссылки должен ясно описывать место назначения или результат перехода. Избегайте расплывчатого текста вроде «Нажмите здесь».

## Поведение клавиатуры

- Ссылки должны быть доступны в обычном порядке табуляции.
- По возможности место назначения должно быть понятно из одного текста ссылки.

## Поведение фокуса

- Фокус должен попадать на якорь или корень, ведущий себя как ссылка.
- Видимое оформление фокуса должно сохраняться внутри сплошного текста и в плотных макетах.

## Семантика для скринридеров

- Ссылка должна оставаться ссылкой, если потребитель намеренно не меняет семантику через `asChild`.
- Встроенные ссылки должны естественно читаться в окружающем тексте.

## Семантика форм

- Ссылки служат для навигации, а не являются элементами управления формы.
- Вспомогательные навигационные ссылки в формах должны оставаться явно второстепенными по отношению к действиям отправки.

## Риски доступности

- Расплывчатый текст ссылки.
- Использование ссылок для действий, изменяющих состояние.
- Стилизация ссылки под кнопку без сохранения навигационной семантики.
