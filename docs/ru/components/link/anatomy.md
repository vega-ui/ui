# Link: анатомия

## Обзор

`Link` — единая текстовая поверхность для навигации. Её анатомия — один корень наподобие якоря плюс встроенное или самостоятельное текстовое содержимое; при желании корень рендерится через `asChild`.

## Обязательные части

### `Link`

Обязательна. Отвечает за стилизацию ссылки и семантику якоря при прямом рендере.

## Необязательные части

`Link` не предоставляет публичных дочерних частей.

## Порядок композиции

1. `Link`
2. встроенное или самостоятельное текстовое содержимое

## Корректные варианты композиции

<!-- example: link/basic-usage.tsx -->
```tsx
import { Link, Text } from '@vega-ui/react';

export default function BasicUsage() {
  return (
    <Text size={3} style={{ width: '100%' }}>
      Exports include every invoice from the selected period. Read how we calculate{' '}
      <Link href='/docs/billing/taxes'>VAT for EU customers</Link>{' '}
      before sharing the file with your accountant.
    </Text>
  );
}
```
<!-- /example -->

## Некорректные варианты композиции

### Ссылка для изменения состояния

Если взаимодействие изменяет состояние, а не выполняет переход, используйте `Button`.

### Расплывчатый текст ссылки

Встроенный текст вроде «Нажмите здесь» ухудшает просматриваемость и доступность.
