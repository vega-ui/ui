# Link

## Профиль документа

`primitive`

## Кратко

`Link` — компонент текстового навигационного действия для встроенных и самостоятельных переходов. Это выбор по умолчанию, когда взаимодействие меняет местоположение, а не изменяет состояние.

## Импорт

```tsx
import { Link, type LinkProps } from '@vega-ui/react';
```

## Экспортируемые типы

- `LinkProps`

## Базовое использование

<!-- example: link/basic-usage.tsx -->
```tsx
import { Link, Text } from '@vega-ui/react';

export default function BasicUsage() {
  return (
    <Text size={3} style={{ width: '100%' }}>
      Exports include every invoice from the selected period. Read how we calculate{' '}
      <Link href='/docs/billing/taxes'>VAT for EU customers</Link>{' '}
      before sharing the file with your accountant.
    </Text>
  );
}
```
<!-- /example -->

## Варианты

- Встроенная текстовая ссылка или самостоятельное навигационное действие
- Рендер якоря по умолчанию или композиция через `asChild`

## Пограничные случаи

- Используйте настоящие цели навигации, а не поведение кнопки, замаскированное под ссылку.
- `asChild` полезен для интеграции с роутерами при сохранении стилизации ссылки.
- Проверяйте поведение фокуса и подчёркивания в сочетании с окружающей типографикой.
- Если нужна выразительная поверхность призыва к действию, `Button asChild` может быть понятнее обычной текстовой ссылки.

## Частые ошибки

- Использование `Link` для действий, изменяющих состояние.
- Стилизация ссылки под кнопку без учёта семантики.
- Расплывчатый текст ссылки вроде «Нажмите здесь».
