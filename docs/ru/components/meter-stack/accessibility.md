# MeterStack: доступность

## Подписи

- Окружающий текст должен объяснять, что представляет составная метрика.

## Поведение клавиатуры

- У `MeterStack` нет поведения клавиатуры.

## Поведение фокуса

- По умолчанию компонент не фокусируется.

## Семантика для скринридеров

- Каждый сегмент предоставляет `role='meter'` с общим контекстом min/max.
- Сегментированные индикаторы бывает трудно понять только по внешнему виду, поэтому часто нужны текстовые подписи рядом.

## Семантика формы

- `MeterStack` только отображает данные и не является полем формы.

## Риски доступности

- нет текстового объяснения, что означают сегменты
- сегменты различаются только цветом
