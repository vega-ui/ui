# MeterStack: анатомия

## Обзор

`MeterStack` задаёт один общий диапазон значений и рендерит несколько сегментов внутри одной заполняемой поверхности. Каждый сегмент объявляет собственное значение относительно max корня.

## Обязательные части

### `MeterStack`

Обязательная часть. Отвечает за общий диапазон значений, размер и фоновую дорожку.

### `MeterStackSegment`

Обязательна в обычной композиции. Рендерит один пропорциональный сегмент.

## Необязательные части

### Переопределение цвета сегментов

Необязательно. Каждый сегмент может переопределить свой цвет через CSS-переменные.

## Порядок композиции

1. `MeterStack`
2. повторяющиеся `MeterStackSegment`

## Допустимые варианты композиции

<!-- example: meter-stack/minimal-composition.tsx -->
```tsx
import { MeterStack, MeterStackSegment } from '@vega-ui/react';

export default function MinimalComposition() {
  return (
    <MeterStack value={0.8} max={1} role='group' aria-label='Disk usage' fullWidth>
      <MeterStackSegment value={0.5} aria-label='Apps' />
      <MeterStackSegment value={0.3} aria-label='Photos' />
    </MeterStack>
  );
}
```
<!-- /example -->

## Недопустимые варианты композиции

### Значения сегментов не отражают задуманную сумму

Визуальному индикатору перестают доверять.

### Слишком много микросегментов без пояснений

Компонент становится визуально шумным и трудным для понимания.
