# MeterStack: сравнение

## Быстрое правило выбора

Используйте `MeterStack`, когда метрику проще всего понять как несколько цветных частей. Используйте `Meter` или `Progress`, когда одна сплошная полоса передаёт значение яснее.

## `MeterStack` или `Meter`

Используйте `MeterStack`, когда:

- главное сообщение — именно состав из сегментов

Используйте `Meter`, когда:

- достаточно одного непрерывного значения в границах

## `MeterStack` или `Progress`

Используйте `MeterStack`, когда:

- интерфейс показывает разбивку по составу

Используйте `Progress`, когда:

- интерфейс показывает выполнение одной задачи во времени

## Выбирайте этот компонент, когда

- одна метрика состоит из нескольких значимых сегментов
- порядок и цвет сегментов несут реальную информацию
- сама разбивка важнее одного итогового значения

## Не выбирайте этот компонент, когда

- достаточно одной сплошной полосы
- смысл сегментов неясен или чисто декоративен
