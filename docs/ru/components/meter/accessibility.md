# Meter: доступность

## Подписи

Обычно рядом с индикатором должен быть текст, объясняющий, что именно измеряется.

## Поведение клавиатуры

- Статичным индикаторам обычно не нужен фокус.

## Поведение фокуса

- `Meter` обычно не получает фокус, если только не входит в более крупный интерактивный паттерн.

## Семантика для скринридеров

- Корень использует `role='meter'`.
- Используйте `valueText`, когда сырого числового значения недостаточно, чтобы объяснить измерение.
- Смену цвета по порогам всё равно нужно объяснять текстом или контекстом.

## Семантика в формах

- `Meter` не является элементом формы.

## Риски доступности

- Индикатор без пояснения, что означает значение.
- Опора только на смену семантического цвета.
- Использование meter для асинхронного выполнения вместо измерения.
