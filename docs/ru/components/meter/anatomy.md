# Meter: анатомия

## Обзор

`Meter` — [составной компонент](../../glossary.md#составной-компонент-compound-component), потому что корень с ролью meter и видимая дорожка разделяют одну модель ограниченного измерения.

## Обязательные части

### `Meter`

Обязательна. Отвечает за значения диапазона, пороги, вариант, размер и атрибуты доступности.

### `MeterTrack`

Обязательна. Рендерит видимую заполненную часть измерения.

## Необязательные части

Помимо корня и дорожки, `Meter` не предоставляет других публичных частей.

## Порядок композиции

1. `Meter`
2. `MeterTrack`

## Допустимые паттерны композиции

<!-- example: meter/minimal-composition.tsx -->
```tsx
import { Meter, MeterTrack } from '@vega-ui/react';

export default function MinimalComposition() {
  return (
    <Meter value={0.72} valueText='72%' aria-label='Disk usage' fullWidth>
      <MeterTrack />
    </Meter>
  );
}
```
<!-- /example -->

## Недопустимые паттерны композиции

### Meter для отображения текущего асинхронного выполнения

Если значение отражает выполнение во времени, лучше подходит `Progress`.

### Цвета по порогам без объяснения смысла диапазона

Пользователи могут увидеть смену семантического цвета, но не понять, что измеряется.
