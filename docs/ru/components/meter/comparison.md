# Meter: сравнение

## Быстрое правило выбора

Используйте `Meter` для ограниченного измерения, а не для текущего выполнения.

## `Meter` или `Progress`

Используйте `Meter`, когда:

- значение — оценка, квота, ёмкость или другое ограниченное измерение

Используйте `Progress`, когда:

- значение отражает выполнение задачи во времени

Главный компромисс: meter описывает измерение, а progress — выполнение во времени.

## `Meter` или `Badge`

Используйте `Meter`, когда:

- интерфейсу нужна количественная визуализация диапазона

Используйте `Badge`, когда:

- интерфейсу нужна только короткая метка категории или статуса

Главный компромисс: meter визуализирует количество, а badge подписывает состояние.

## `Meter` или `MeterStack`

Используйте `Meter`, когда:

- одно непрерывное ограниченное значение — самое понятное представление

Используйте `MeterStack`, когда:

- должны оставаться видимыми несколько частей одного целого

## Выбирайте этот компонент, когда

- Значение ограничено и носит описательный характер.
- Важны пороги или оптимальное состояние.
- Полезна количественная визуализация в виде полосы.
- одно непрерывное измерение понятнее разбивки на сегменты

## Не выбирайте этот компонент, когда

- Значение отражает текущее выполнение.
- Интерфейсу нужна лишь короткая текстовая метка.
- Осмысленного диапазона нет.
