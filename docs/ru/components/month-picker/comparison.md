# MonthPicker: сравнение

## Быстрое правило выбора

Используйте `MonthPicker`, когда пользователь выбирает месяц из сетки. Для конкретных дат используйте `DayPicker`, для выбора года — `YearPicker`.

## `MonthPicker` и `DayPicker`

- `MonthPicker` — для выбора на уровне месяца.
- `DayPicker` — для выбора на уровне дня.

## `MonthPicker` и `YearPicker`

- `MonthPicker` — для месяца в контексте года.
- `YearPicker` — когда целью выбора является сам год.

## Выбирайте этот компонент, когда

- значение — месяц
- подходящее взаимодействие — плотная сетка месяцев

## Не выбирайте этот компонент, когда

- пользователю нужна конкретная дата или год, а не месяц
