# NumberField: решение проблем

## Значение неожиданно прыгает при вводе

### Симптом

Пользователь вводит число, но промежуточное значение ведёт себя нестабильно.

### Вероятная причина

Во время промежуточных состояний редактирования ввод обрабатывается как полностью разобранное число.

### Как проверить

- введите частичные значения, например `-`, `1.` или пустую строку
- посмотрите, как реагирует состояние родителя

### Исправление

Допускайте промежуточные строковые состояния при вводе и разбирайте значение только в подходящий момент.

## Кнопки шага и введённое значение расходятся

### Симптом

В поле можно вводить и менять значение по шагу, но эти два способа взаимодействия не остаются синхронизированными.

### Вероятная причина

Пользовательская логика родителя обходит собственную модель шага и границ корня.

### Как проверить

- сравните изменения вводом и нажатиями кнопок в одном и том же поле

### Исправление

Используйте один источник истины и оставьте логику шага корня главной.

## Колесо мыши неожиданно меняет значение

### Симптом

Прокрутка над элементом управления меняет число, хотя пользователь хотел только прокрутить страницу.

### Вероятная причина

`changeOnWheel` включён в контексте, где изменение колесом неожиданно.

### Как проверить

- переведите фокус на поле и прокрутите над ним

### Исправление

Отключите `changeOnWheel` в этой интеграции или уберите элемент управления из областей с активной прокруткой.
