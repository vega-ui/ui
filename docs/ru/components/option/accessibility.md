# Option: доступность

## Именование

- Окружающий список или селектор должен пояснять, что представляют варианты.

## Поведение клавиатуры

- У `Option` нет собственного поведения клавиатуры: клавиши обрабатывает владелец списка.

## Поведение фокуса

- `Option` не получает фокус. Его держит владелец списка и указывает на активный вариант через `aria-activedescendant`.
- `active` показывает, какой это вариант.

## Семантика для скринридеров

- Компонент рендерит `role='option'`.
- `aria-selected` выставляется, когда передан `selected`, а `aria-disabled` — когда передан `disabled`.

## Семантика формы

- `Option` сам по себе не является нативным полем формы.

## Риски доступности

- использование `Option` без подходящего родительского паттерна listbox или меню
- опора только на цвет выбранного варианта без окружающего контекста или семантики выбора
