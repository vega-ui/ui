# Option: сравнение

## Быстрое правило выбора

Используйте `Option`, когда строите спископодобную поверхность выбора, которая должна совпадать со стилем вариантов VegaUI. Для обычных действий используйте `Button`, а `SelectOption` — когда у вас уже есть полная композиция `Select`.

## `Option` и `Button`

- `Option` — для выбираемых строк списка.
- `Button` — для прямых действий.

## `Option` и `SelectOption`

- `Option` — когда строите собственный примитив выбора.
- `SelectOption` — внутри полной подсистемы `Select`.

## Выбирайте этот компонент, когда

- нужна переиспользуемая презентационная строка варианта
- родительский паттерн уже владеет логикой выбора

## Не выбирайте этот компонент, когда

- нужна полноценная система выбора без дополнительной работы
- строка на самом деле действие, а не выбираемый вариант
