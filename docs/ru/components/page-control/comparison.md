# PageControl: сравнение

## Быстрое правило выбора

Используйте `PageControl` для коротких последовательностей, например шагов онбординга или каруселей. Используйте `Pagination` для настоящей навигации по страницам наборов результатов.

## `PageControl` и `Pagination`

- Используйте `PageControl` для коротких компактных последовательностей.
- Используйте `Pagination` для явных номеров страниц и навигации по наборам данных.

## `PageControl` и `Stepper`

- Используйте `PageControl`, когда индикаторы намеренно минимальны.
- Используйте более полный паттерн степпера, когда важны подписи шагов и более подробный статус.

## Выбирайте этот компонент, когда

- последовательность короткая
- достаточно компактных индикаторов

## Не выбирайте этот компонент, когда

- пользователям нужны номера страниц или адресуемые переходы
- каждому шагу нужны видимые подписи и более подробное состояние
