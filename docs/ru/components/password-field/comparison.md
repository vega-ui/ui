# PasswordField: сравнение

## Быстрое правило выбора

Используйте `PasswordField`, когда пользователь вводит секрет и ему может понадобиться ненадолго его показать. Для обычного текстового ввода используйте `TextField`.

## `PasswordField` или `TextField`

Используйте `PasswordField`, когда:

- значение — скрытый секрет с возможностью показать его

Используйте `TextField`, когда:

- поле предназначено для обычного текста

## `PasswordField` или `PinField`

Используйте `PasswordField`, когда:

- секрет произвольной формы

Используйте `PinField`, когда:

- секрет — короткий код фиксированной длины

## Выбирайте этот компонент, когда

- значение должно быть скрыто по умолчанию
- возможность показать и скрыть помогает проверить ввод
- важна работа менеджеров паролей и браузерного ввода секретов

## Не выбирайте этот компонент, когда

- поле не содержит секрета
- значение — одноразовый код (OTP) или PIN фиксированной длины
