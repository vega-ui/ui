# PinField: сравнение

## Быстрое правило выбора

Используйте `PinField` для коротких кодов фиксированной длины, которым помогает сегментированное отображение. Используйте `PasswordField` для секретных строк и `TextField` для обычного текста.

## `PinField` и `PasswordField`

Используйте `PinField`, когда:

- значение — одноразовый код (OTP) или короткий код подтверждения

Используйте `PasswordField`, когда:

- значение — более длинная секретная строка с возможностью показать или скрыть её

## `PinField` и `TextField`

Используйте `PinField`, когда:

- сегментация упрощает чтение и ввод

Используйте `TextField`, когда:

- поле — обычный свободный ввод

## Выбирайте этот компонент, когда

- длина кода фиксированная и небольшая
- сегментированный ввод помогает просматривать и исправлять код
- вставка и автопереход к следующему слоту — ожидаемая часть UX

## Не выбирайте этот компонент, когда

- значение произвольное
- полю нужно обычное редактирование текста, а не ввод по слотам
