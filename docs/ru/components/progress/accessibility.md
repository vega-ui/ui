# Progress: доступность

## Подписи

Рядом с индикатором прогресса обычно должен быть видимый текст, который объясняет, что именно выполняется.

## Поведение клавиатуры

- Статичным индикаторам прогресса обычно не нужен фокус.

## Поведение фокуса

- `Progress` обычно не фокусируется, если только окружающий паттерн не делает его интерактивным.

## Семантика для скринридеров

- Корень использует `role='progressbar'`.
- Используйте `valueText`, когда простого числового значения недостаточно, чтобы объяснить состояние.
- Неопределённому прогрессу всё равно нужен поясняющий контекст в окружающем тексте.

## Семантика форм

- `Progress` не является элементом управления формы.

## Риски доступности

- Показ прогресса без указания того, что именно выполняется.
- Определённые значения, которые не соответствуют реальному состоянию задачи.
- Использование прогресса для статичных описательных измерений.
