# Progress: анатомия

## Обзор

`Progress` — [составной компонент](../../glossary.md#составной-компонент-compound-component), потому что корень с ролью progressbar и видимая полоса заполнения разделяют одну модель значения и один контракт состояния.

## Обязательные части

### `Progress`

Обязательна. Отвечает за значения диапазона, вариант, размер и атрибуты доступности.

### `ProgressTrack`

Обязательна. Рендерит видимую величину заполнения или анимацию неопределённого состояния.

## Необязательные части

Кроме корня и полосы, `Progress` не предоставляет других публичных частей.

## Порядок композиции

1. `Progress`
2. `ProgressTrack`

## Допустимые варианты композиции

<!-- example: progress/minimal-composition.tsx -->
```tsx
import { Progress, ProgressTrack } from '@vega-ui/react';

export default function MinimalComposition() {
  return (
    <Progress value={40} aria-label='Upload progress' fullWidth>
      <ProgressTrack />
    </Progress>
  );
}
```
<!-- /example -->

## Недопустимые варианты композиции

### Прогресс без поясняющего окружающего контекста

Пользователи увидят полосу, но не поймут, что именно продвигается.

### Статичная оценка, показанная как прогресс

Если значение описательное, а не связанное со временем, обычно лучше подходит `Meter`.
