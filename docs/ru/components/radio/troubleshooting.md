# Radio: решение проблем

## Можно отметить несколько радиокнопок сразу

### Симптом

Выбранными выглядят несколько вариантов, хотя интерфейс должен разрешать только один.

### Вероятная причина

У радиокнопок нет общего нативного `name`.

### Как проверить

- Изучите отрендеренный атрибут `name`.
- Проверьте, используют ли все варианты группы одно и то же значение.

### Решение

- Задайте всем связанным радиокнопкам одинаковый `name`.
- Разделяйте несвязанные группы разными именами.

## Кликабельным кажется только крошечный контрол

### Симптом

Пользователи промахиваются мимо строки с подписью, потому что интерактивным кажется только кружок радиокнопки.

### Вероятная причина

Видимый текст не обёрнут в ту же кликабельную структуру `label`.

### Как проверить

- Наведите курсор и кликните по тексту рядом с контролом.
- Убедитесь, что `label` оборачивает и радиокнопку, и текст.

### Решение

- Используйте оборачивающий `label` для контрола и его текста.
- По возможности делайте кликабельной всю строку.

## Radio использован не для той модели выбора

### Симптом

Технически интерфейс работает, но пользователи ожидают, что можно выбрать несколько элементов или независимо переключить одну настройку.

### Вероятная причина

`Radio` выбран там, где модели продукта лучше соответствует `Checkbox` или `Switch`.

### Как проверить

- Определите, является ли выбор взаимоисключающим, независимым или бинарным.
- Сравните сценарий с другими контролами выбора в системе.

### Решение

- Используйте `Checkbox` для независимых вариантов.
- Используйте `Switch` для одной бинарной настройки, применяемой сразу.
