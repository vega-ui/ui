# Separator: сравнение

## Быстрое правило выбора

Используйте `Separator` для лёгкого визуального разделения. Используйте `Heading` или `Fieldset`, когда интерфейсу нужна именованная структура, а не просто линия.

## `Separator` или `Fieldset`

- Используйте `Separator` для визуального разделения.
- Используйте `Fieldset` для семантики группы полей формы.

## `Separator` или `Heading`

- Используйте `Separator`, когда видимый заголовок не нужен.
- Используйте `Heading`, когда разделу нужна семантическая подпись.

## `Separator` или `Card`

- Используйте `Separator` внутри существующей раскладки.
- Используйте `Card`, когда всему разделу нужна собственная поверхность.

## Выбирайте этот компонент, когда

- двум соседним областям нужен ненавязчивый разделитель
- семантическая группировка уже решена в другом месте

## Не выбирайте этот компонент, когда

- разделу нужна подпись
- набору контролов нужна нативная семантика группы
