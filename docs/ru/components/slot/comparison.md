# Slot: сравнение

## Быстрое правило выбора

Используйте `Slot`, только когда строите низкоуровневую полиморфную композицию. В обычном продуктовом коде предпочитайте высокоуровневые API `asChild`.

## `Slot` или `asChild` у компонентов

- Используйте `Slot`, когда пишете примитивы или обёртки.
- Используйте `asChild` у существующих компонентов VegaUI в продуктовом коде.

## `Slot` или прямой рендер элемента

- Рендерите элемент напрямую, когда слияние пропсов не нужно.
- Используйте `Slot`, когда пропсы родителя нужно слить с выбранным дочерним элементом.

## Выбирайте этот компонент, когда

- вы расширяете внутренности дизайн-системы
- вам нужна семантика слияния пропсов с единственным дочерним элементом

## Не выбирайте этот компонент, когда

- компонент уже предоставляет `asChild`
- вам нужен просто обычный элемент
