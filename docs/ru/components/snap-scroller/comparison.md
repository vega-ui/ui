# SnapScroller: сравнение

## Быстрое правило выбора

Используйте `SnapScroller`, когда у страниц уже есть стабильные индексы и нужно только прямое постраничное пролистывание с привязкой. Используйте `IndexedSnapScroller`, когда прокрутка должна управлять скользящим окном логических индексов.

## `SnapScroller` и `IndexedSnapScroller`

- `SnapScroller` — для уже существующих страниц с ключами.
- `IndexedSnapScroller` — для почти бесконечного пролистывания с окном индексов.

## `SnapScroller` и `PageControl`

- `SnapScroller` — для самой поверхности со страницами.
- `PageControl` — как компактный индикатор или контроллер для короткой последовательности.

## Выбирайте этот компонент, когда

- у страниц стабильные индексы
- достаточно колбэков привязки и императивных prev/next

## Не выбирайте этот компонент, когда

- список страниц должен виртуально расширяться или сдвигаться
- достаточно простого индикатора без поверхности с привязкой
