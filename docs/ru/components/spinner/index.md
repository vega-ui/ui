# Spinner

## Профиль документа

`primitive`

## Кратко

`Spinner` — индикатор загрузки для состояний ожидания и асинхронных действий. Его размер задаётся числом, а цвет — вариантами primary или secondary; он подходит, когда интерфейсу нужна лишь компактная обратная связь о процессе с неопределённой длительностью.

## Импорты

```tsx
import {
  Spinner,
  type SpinnerProps,
  type SpinnerSize,
  type SpinnerVariant,
} from '@vega-ui/react';
```

## Экспортируемые типы

- `SpinnerProps`
- `SpinnerSize`
- `SpinnerVariant`

## Базовое использование

<!-- example: spinner/basic-usage.tsx -->
```tsx
import { Spinner } from '@vega-ui/react';

export default function BasicUsage() {
  return <Spinner size={3} aria-label='Loading messages' />;
}
```
<!-- /example -->

## Варианты

- Размер: от `1` до `11`
- Вариант: `primary` или `secondary`
- Размещение: в строке, внутри контролов или по центру поверхностей

## Пограничные случаи

- Спиннер без контекста может быть непонятен.
- Слишком крупные спиннеры внутри компактных контролов нарушают баланс.
- Индикаторы загрузки по возможности должны сохранять стабильность раскладки.
- Если точная степень завершения известна, полоса `Progress` обычно передаёт состояние лучше спиннера.

## Частые ошибки

- Показывать одинокий спиннер без поясняющего контекста.
- Заменять спиннером слишком много содержимого, когда скелетон или сохранённая раскладка были бы понятнее.
- Использовать один и тот же размер для загрузки в кнопке и загрузки страницы.
