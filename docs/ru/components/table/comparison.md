# Table: сравнение

## Быстрое правило выбора

Используйте `Table`, когда достаточно нативной семантической структуры таблицы, а взаимодействие в стиле grid не нужно.

## `Table` или `DataGrid`

Используйте `Table`, когда:

- данные в основном только для чтения
- главное требование — нативная семантика таблицы
- навигация с клавиатуры по ячейкам не нужна

Используйте `DataGrid`, когда:

- функции нужны более богатое взаимодействие с клавиатуры, выбор или поведение грида

Главный компромисс: `Table` проще и семантичнее, а `DataGrid` справляется с более тяжёлыми моделями взаимодействия.

## `Table` или `DataGridSelectable`

Используйте `Table`, когда:

- выбор строк не входит в основную модель взаимодействия

Используйте `DataGridSelectable`, когда:

- пользователям нужен явный выбор строк

Главный компромисс: `Table` избегает сложности грида, а `DataGridSelectable` добавляет семантику и контролы выбора.

## Выбирайте этот компонент, когда

- Данные табличные и в основном только для чтения.
- Нативная семантическая структура важнее продвинутого взаимодействия.
- Таблица должна оставаться простой и предсказуемой.

## Не выбирайте этот компонент, когда

- Функции нужно поведение клавиатуры в стиле grid.
- Центральную роль играют выбор, встроенное редактирование или более богатое взаимодействие со строками.
- Интерфейс по сути — грид данных, а не семантическая таблица.
