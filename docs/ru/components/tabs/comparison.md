# Tabs: сравнение

## Быстрое правило выбора

Используйте `Tabs`, когда одна область показывает одну из нескольких панелей связанного содержимого и пользователь переключается между ними на той же странице.

## `Tabs` или `SegmentedControl`

Используйте `Tabs`, когда:

- каждый вариант показывает свою панель содержимого
- панели — разделы одной страницы

Используйте `SegmentedControl`, когда:

- выбор — это значение, например режим просмотра или фильтр, которое меняет одну общую область или отправляется с формой

Главный компромисс: вкладки — это `tablist`, у которого есть панели, а сегментированный контрол — группа радиокнопок, которая выбирает значение.

## `Tabs` или `Accordion`

Используйте `Tabs`, когда:

- достаточно одного раздела за раз и разделы равноправны
- по горизонтали хватает места для подписей

Используйте `Accordion`, когда:

- несколько разделов могут быть открыты вместе или экран узкий
- разделы должны читаться сверху вниз

Главный компромисс: вкладки сохраняют высоту страницы и прячут остальные разделы, а аккордеон оставляет все заголовки в порядке чтения.

## `Tabs` или навигационные ссылки

Используйте `Tabs`, когда:

- переключение не меняет URL и показывает содержимое, которое уже есть на странице

Используйте `<nav>` со ссылками, когда:

- у каждого варианта свой URL, им нужно делиться или он загружает новую страницу. Отметьте текущую ссылку `aria-current="page"`; для пронумерованных страниц есть [Pagination](../pagination/), для индикаторов слайдов — [PageControl](../page-control/).

Главный компромисс: вкладки переключают содержимое на месте, ссылки переходят; скринридеры объявляют их по-разному.

## Выбирайте этот компонент, когда

- Несколько равноправных разделов делят одну область страницы
- Пользователь сравнивает или переключает представления одного объекта, например настройки, детали и активность
- Содержимое должно оставаться смонтированным, пока скрыто, и сохранять состояние

## Не выбирайте этот компонент, когда

- Каждый вариант — отдельная страница или URL
- Выбор — значение формы
- Пользователю нужно видеть несколько разделов одновременно
