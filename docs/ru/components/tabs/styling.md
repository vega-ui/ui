# Tabs: стилизация

## Обзор

`TabsList` рисует линию под выбранной вкладкой; вертикальный список рисует ещё и рейку вдоль начального края, и линия лежит на ней; `--tabs-separator-color: transparent` убирает рейку. Выбранная вкладка — CSS-якорь (`anchor-name: --tabs-selected`), а линия — псевдоэлемент `::after` у `TabsList`, который следует за ней через CSS anchor positioning, без измерений в JS. В Chromium и Safari линия плавно переезжает между вкладками; Firefox переносит её без анимации. При наведении на невыбранную вкладку под ней появляется приглушённая линия. В браузерах без anchor positioning линия рисуется под самой выбранной вкладкой, без движения.

## Публичные CSS-переменные

| Переменная | Где используется | Назначение |
| --- | --- | --- |
| `--tabs-indicator-color` | `Tabs` | Цвет линии под выбранной вкладкой; его задаёт `variant`. |
| `--tabs-separator-color` | `TabsList` | Цвет линии вдоль списка: прозрачная у горизонтального списка, рейка у вертикального. |
| `--tabs-tab-height` | `TabsTab` | Высота вкладки; её задаёт `size`. |
| `--focus-color` | `TabsTab`, `TabsPanel` | Цвет обводки фокуса. |
| `--duration-spring` | `TabsList`, `TabsTab` | Длительность движения линии и смены цвета вкладки; обе используют `--ease-smooth`. |
| `--transition-fast-state-delay` | `TabsTab` | Длительность появления и исчезновения линии при наведении. |

## Переменные на уровне частей

- `Tabs`: цвет линии по `data-variant`; при `data-orientation="vertical"` выстраивает список и панели в строку, иначе это обычный блок.
- `TabsList`: flex-строка (или колонка в вертикальном режиме), разделитель, линия и отступ перед панелями. Отступ — внешний отступ списка, а не `gap` на корне, потому что скрытые панели сохраняют блок.
- `TabsTab`: высота и размер шрифта по `data-size`, без внутренних отступов по строке, вторичный цвет подписи, основной цвет у выбранной вкладки и при наведении, приглушённая линия при наведении, цвет отключённой вкладки. В вертикальном списке у вкладок есть внутренние отступы, а текст выровнен по началу.
- `TabsPanel`: только обводка фокуса. Ни `display`, ни отступов она не задаёт.

## Взаимодействие состояний и вариантов

- `[aria-selected="true"]` или `[data-selected="true"]` отмечает выбранную вкладку и её панель.
- `size` задаёт `data-size` списку и вкладкам: `sm`, `md` или `lg`.
- `variant` задаёт `data-variant` корню: `primary` рисует линию основным цветом, `secondary` (по умолчанию) — вторичным.
- `orientation` задаёт `aria-orientation` списку и `data-orientation` корню: у вертикального списка рейка и линия находятся с начальной стороны строки.
- `:disabled` у вкладки даёт цвет отключённой подписи и не показывает линию при наведении.
- `prefers-reduced-motion: reduce` заменяет движение линии её появлением под выбранной вкладкой.

## Примеры

```css
.compactTabs [role='tab'] {
  --tabs-tab-height: 28px;
}
```
<!-- /example -->

```css
.successTabs [role='tablist'] {
  --tabs-indicator-color: var(--color-green-500);
  --tabs-separator-color: var(--separator-non-opaque);
}

.railLessTabs [role='tablist'] {
  --tabs-separator-color: transparent;
}
```

## Что не переопределять

- Не задавайте `display`, отступы, рамки и внешние отступы самой `TabsPanel`: скрытые панели с `hidden="until-found"` сохраняют блок. Ставьте их на элемент внутри панели.
- Не ставьте flex- или grid-`gap` на элемент, который содержит панели, и не давайте `TabsPanel` `flex: 1`: каждая скрытая панель добавит промежуток или заберёт свою долю места. Задавайте размеры обёртке вокруг панелей.
- Не задавайте геометрию линии вручную: её положение и размер берутся из якоря выбранной вкладки.
- Не убирайте обводку фокуса у вкладок и у показанной панели.
