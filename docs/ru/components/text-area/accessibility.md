# TextArea: доступность

## Подписи

- Сопровождайте `TextArea` видимым `Label`.

## Поведение клавиатуры

- Поведение клавиатуры соответствует нативному textarea.

## Поведение фокуса

- Фокус находится на самом textarea.
- Поле рисует собственную обводку фокуса.

## Семантика для скринридеров

- `TextArea` рендерит нативный `<textarea>`.
- У элемента управления должна быть видимая подпись и, при необходимости, вспомогательный текст, связанный через described-by.

## Семантика форм

- Используйте нативные пропсы textarea для `name`, `required` и работы со значением.
- Применяйте семантику невалидного состояния к textarea, когда поле действительно невалидно.

## Риски доступности

- отсутствие видимой подписи
- текст плейсхолдера как единственная подсказка
- ошибка, показанная только красной обводкой
