# TextArea: сравнение

## Быстрое правило выбора

Используйте `TextArea` для многострочного ввода в свободной форме. Используйте `TextField` для однострочного ввода.

## `TextArea` или `TextField`

Используйте `TextArea`, когда:

- содержимое — комментарии, описания, заметки или другой многострочный текст

Используйте `TextField`, когда:

- значение однострочное или требует композиции с префиксом/суффиксом

## `TextArea` или `Code`

Используйте `TextArea`, когда:

- пользователь редактирует связный или обычный текст

Используйте `Code`, когда:

- интерфейс показывает фрагменты кода в строке, а не редактирует длинный текст

## Выбирайте этот компонент, когда

- значение многострочное
- пользователям может понадобиться больше места по вертикали, чтобы просмотреть введённое
- переносы строк — часть реальной модели данных

## Не выбирайте этот компонент, когда

- поле содержит короткое однострочное значение
- элементу управления нужно насыщенное составное поведение, например переключатели или сегментированные слоты
