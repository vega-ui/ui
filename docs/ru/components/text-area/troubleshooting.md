# TextArea: решение проблем

## Поле слишком маленькое для ожидаемого содержимого

### Симптом

Пользователям нужно вводить длинный текст, но видимая область кажется тесной.

### Вероятная причина

`TextArea` используется со слишком малой шириной вокруг или в раскладке недостаточного размера.

### Как проверить

- сравните поле в более широкой раскладке
- протестируйте с содержимым реалистичной длины

### Исправление

Используйте `fullWidth`, увеличьте доступное пространство или пересмотрите раскладку формы.

## Стиль ошибки виден, но пользователи всё равно не замечают проблему

### Симптом

Обводка поля красная, но пользователи не понимают, что не так.

### Вероятная причина

Применено только визуальное состояние ошибки.

### Как проверить

- проверьте, есть ли видимое сообщение об ошибке

### Исправление

Дополните состояние ошибки конкретным `HelperText` или другим текстом валидации.

## Компонент используется для коротких однострочных значений

### Симптом

Поле выглядит визуально тяжёлым для простого значения вроде имени или URL.

### Вероятная причина

`TextArea` выбран там, где уместнее `TextField`.

### Как проверить

- оцените типичную длину пользовательского ввода

### Исправление

Переключитесь на `TextField` для однострочных значений.
