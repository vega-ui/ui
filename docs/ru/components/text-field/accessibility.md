# TextField: доступность

## Подписи

- Сопровождайте `TextFieldInput` видимым `Label`.
- Подпись должна указывать на инпут, а не на обёртку.

## Поведение клавиатуры

- Поведение клавиатуры — нативное для элемента ввода и необязательных элементов управления в префиксе и суффиксе.

## Поведение фокуса

- Фокус попадает на `TextFieldInput`, а не на `TextField`.
- Обёртка отрисовывает стиль фокуса, когда инпут в фокусе.

## Семантика для скринридеров

- Значимый элемент управления — нативный инпут.
- Содержимое префикса и суффикса не должно мешать доступному имени поля.

## Семантика форм

- Используйте `name`, `value`, `defaultValue`, `required` и похожие пропсы формы на `TextFieldInput`.
- Используйте `error` на обёртке только для визуального отображения; при необходимости задавайте семантику невалидности на инпуте.

## Риски доступности

- нет видимой подписи
- визуальная ошибка без семантики невалидности на инпуте
- слишком много соседних элементов управления в одной строке поля
