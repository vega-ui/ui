# Text: доступность

## Подпись

- `Text` сам по себе не создаёт подписей.
- Когда текст подписывает элемент управления, используйте `Label` или `FieldsetLegend`.

## Поведение клавиатуры

- У `Text` нет поведения клавиатуры.

## Поведение фокуса

- `Text` обычно не получает фокус, если только `asChild` не объединяет его с фокусируемым элементом.

## Семантика для скринридеров

- Семантика для скринридеров зависит от отрендеренного элемента.
- Если нужны семантические заголовки, используйте `Heading`, а не стилизуйте `Text` под заголовок.

## Семантика форм

- `Text` подходит для поясняющего текста, описаний и сообщений валидации рядом с полями.

## Риски доступности

- использование `Text` как визуального заголовка без семантики заголовка
- низкоконтрастные переопределения для основного содержимого
