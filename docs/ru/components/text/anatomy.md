# Text: анатомия

## Обзор

`Text` — типографский примитив из одной части. Корень владеет всем публичным контрактом размера, начертания и семантической композиции основного текста.

## Обязательные части

### `Text`

Обязательна. Рендерит текстовый узел со стилями основной типографики VegaUI.

## Необязательные части

Экспортируемых дочерних частей нет.

## Порядок композиции

1. `Text`
2. содержимое или целевой элемент `asChild`

## Допустимые варианты композиции

Внешний `Text` рендерит `<p>` через `asChild`; строчные `Text` внутри остаются `<span>` или рендерят семантические элементы вроде `<time>`.

<!-- example: text/valid-composition-patterns.tsx -->
```tsx
import { Text } from '@vega-ui/react';

export default function ValidCompositionPatterns() {
  return (
    <Text asChild size={3}>
      <p>
        Order <Text fontWeight={700}>#4821</Text> ships on{' '}
        <Text asChild>
          <time dateTime='2026-03-14'>March 14</time>
        </Text>
        .
      </p>
    </Text>
  );
}
```
<!-- /example -->
