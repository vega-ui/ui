# Text: сравнение

## Быстрое правило выбора

Используйте `Text` для основного текста, поясняющего текста и описаний. Используйте `Heading`, `Label` или `Code`, когда у содержимого более конкретная семантическая роль.

## `Text` или `Heading`

- Используйте `Text` для абзацев и вспомогательного текста.
- Используйте `Heading` для структуры документа.

## `Text` или `Label`

- Используйте `Text` для общего текста.
- Используйте `Label`, когда текст даёт имя элементу управления формы.

## `Text` или `Code`

- Используйте `Text` для прозы.
- Используйте `Code` для встроенного кода, токенов, команд или идентификаторов.

## Выбирайте этот компонент, когда

- нужна основная типографика из общей шкалы
- семантический смысл задаётся окружающей раскладкой или отрендеренным дочерним элементом

## Не выбирайте этот компонент, когда

- содержимое — заголовок
- содержимое — подпись поля формы
- содержимое должно читаться как встроенный код
