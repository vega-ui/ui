# TimeField: сравнение

## Быстрое правило выбора

Используйте `TimeField`, когда пользователь вводит время без выбора даты. Используйте `DateTimeField`, когда дата и время составляют одно значение.

## `TimeField` или `TextField`

Используйте `TimeField`, когда:

- важен ввод времени по маске с форматом и границами

Используйте `TextField`, когда:

- значение — произвольный текст, даже если в нём есть цифры или разделители

## `TimeField` или `DateTimeField`

Используйте `TimeField`, когда:

- хранимое значение — только время

Используйте `DateTimeField`, когда:

- время неотделимо от даты

## Выбирайте этот компонент, когда

- пользователь должен ввести только время
- полезен ввод по маске
- бизнес-значение — не полная временная метка

## Не выбирайте этот компонент, когда

- значение — полная дата и время
- текст на самом деле не является временем
