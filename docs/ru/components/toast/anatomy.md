# Toast: анатомия

## Обзор

`Toast` делится на очередь, область и шаблон. Очередь — обычный объект вне React, который хранит тосты, самые новые первыми. `ToastRegion` подписывается на очередь, показывает её тосты в верхнем слое и рендерит свои дочерние элементы по одному разу на тост; дочерние элементы — это шаблон, ваш компонент с `Toast` в корне, который читает тост через `useToastContext()`. `ToastClose` закрывает тост, в котором находится. Провайдера нет: код, который добавляет тост, и область, которая его показывает, связывает очередь.

## Обязательные части

### `createToastQueue()`

Создаёт очередь тостов с содержимым вашего типа: `createToastQueue<Notice>()`. `add(content, { timeout })` ставит тост в начало и возвращает его ключ, `close(key)` закрывает его, `toasts` перечисляет их от новых к старым, а `subscribe(listener)` сообщает о каждом изменении. В ней нет React, поэтому тосты могут добавлять и стор, и обработчик запроса, и тест. Создайте её один раз в модуле; две очереди — две независимые стопки.

### `ToastRegion`

Рендерит `<section role="region" aria-live="polite" aria-relevant="additions text" popover="manual">` в собственный контейнер в конце `<body>`, показанный в верхнем слое с самого начала. Принимает `queue`, `limit` — сколько тостов видно одновременно, `swipeDirections` — направления свайпа, который закрывает тост, все HTML-атрибуты и `ref`. Назовите её через `aria-label`. Её дочерние элементы рендерятся по одному разу на каждый показанный тост, каждый с контекстом своего тоста; больше ничего внутрь не кладите. Поверх открытого модального диалога она переносит свой контейнер в этот диалог, а когда диалог закрывается — обратно.

### `Toast`

Рендерит `<div role="status" aria-atomic="true">` для одного тоста, с таймером, свайпом и уходом этого тоста. Он должен быть корнем шаблона. Передайте `role="alert"` для срочного тоста и назовите его через `aria-labelledby`, указывающий на ваш заголовок. Принимает все атрибуты `<div>` и `ref`.

## Необязательные части

### `ToastClose`

Рендерит `<button type="button">`, который закрывает свой тост после вашего `onClick`, если тот не вызвал `event.preventDefault()`. Своих стилей у него нет: через `asChild` он рендерит вашу кнопку, например `Button` с Undo, которая выполняет действие и убирает тост, или `Button` с `square` и иконкой, названную через `aria-label`.

### `useToastContext()`

Читает тост в шаблоне: `content` — значение, переданное в `add()`, типизируется через `useToastContext<Notice>()`; `key` — ключ, который вернул `add()`; `index` — место в стопке, 0 для самого нового; `close()` закрывает тост, как `ToastClose`.

## Порядок композиции

1. Очередь в модуле вне компонентов
2. `ToastRegion` один раз, с очередью и `aria-label`
3. Компонент-шаблон как её единственный дочерний элемент
4. `Toast` в корне шаблона
5. Содержимое тоста и его кнопки `ToastClose` внутри `Toast`

## Корректные варианты композиции

Очередь живёт в своём модуле, а область рендерится один раз; шаблон — один компонент, который читает содержимое каждого тоста и решает его роль, имя, иконку и действия. Действие уведомления — это `ToastClose` с `asChild` вокруг `Button`, поэтому одно нажатие выполняет его и убирает тост, а кнопка закрытия — `Button` с `square` и иконкой, имя которой приходит из пропа.

См. рецепт в разделе [Свой компонент](./index.md#свой-компонент).

## Некорректные варианты композиции

### Очередь, созданная в компоненте

`createToastQueue()` внутри компонента создаёт новую пустую очередь при каждом рендере, и тосты, добавленные в старую, теряются. Создайте очередь один раз на верхнем уровне модуля.

### Несколько областей для одной очереди

Каждая `ToastRegion` показывает все тосты своей очереди: две области для одной очереди показывают и объявляют каждый тост дважды. Рендерите одну область на очередь.

### `Toast` вне шаблона

`Toast` читает свой тост из области. `Toast`, отрендеренный где-то ещё, не получает тоста и таймера; вместо этого добавьте тост в очередь.

### В корне шаблона не `Toast`

Область располагает, складывает и свайпает элементы `Toast`, которые находит среди своих дочерних. Обёртка вокруг `Toast` или текст рядом с ним ломают стопку: оставьте `Toast` корневым элементом шаблона.

### Тост без имени

У `role="alert"` или `role="status"` без `aria-labelledby` нет имени, когда пользователь доходит до него фокусом или скринридером. Компоненты сами подписи не ставят: укажите в `aria-labelledby` заголовок.
