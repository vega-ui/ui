# Toast: стилизация

## Обзор

`ToastRegion` располагает тосты: в правом верхнем углу, а на экране шириной до 40rem — по центру сверху, шириной 22rem и с отступом от краёв и безопасной зоны. `Toast` — компактная карточка на поверхности всплывающих компонентов, `--surface-secondary`, как у `Menu` и `Tooltip`, с тенью `--toast-shadow`, с отступом 8px, 16px перед текстом и углами, скруглёнными вокруг кнопки `xs`; раскладка внутри неё ваша, например flex-строка из заголовка, действия и кнопки закрытия. Тосты складываются в колоду: передний тост целиком, а старые уменьшены за ним, и выглядывают только их края, пока указатель или фокус на тостах не раскроют их в список. Они движутся на пружинах, следуют за свайпом и при уменьшенном движении переходят на проявление. У `ToastClose` своего вида нет: рендерите в нём свою `Button` через `asChild`.

## Публичные CSS-переменные

| Переменная | Где используется | Назначение |
| --- | --- | --- |
| `--toast-inset` | `ToastRegion` | Расстояние области от краёв окна, не меньше безопасной зоны; по умолчанию 16px. На него же сдвигается тост, который входит или уходит. |
| `--toast-gap` | `ToastRegion`, `Toast` | Промежуток между тостами раскрытого списка; по умолчанию 8px. |
| `--toast-peek` | `ToastRegion`, `Toast` | Насколько каждый старый тост выглядывает из-под переднего в свёрнутой колоде; по умолчанию 12px. |
| `--toast-br-ratio` | `ToastRegion`, `Toast` | Степень скругления тостов, как `--button-br-ratio`; по умолчанию `--br-ratio`. |
| `--toast-radius` | `ToastRegion`, `Toast` | Радиус углов тостов; по умолчанию скруглён вокруг кнопки `xs` и её отступа 8px с `--toast-br-ratio`. |
| `--toast-shadow` | `ToastRegion`, `Toast` | Тень тостов; `--surface-shadow` с более близкой тенью, которая отделяет карточки колоды друг от друга. |
| `--duration-spring` | `Toast` | Длительность пружины, которая двигает, масштабирует и меняет размер тостов. |
| `--ease-spring` | `Toast` | Кривая пружины этого движения. |
| `--duration-exit` | `Toast` | Длительность ухода тоста и проявления при уменьшенном движении. |
| `--ease-exit` | `Toast` | Кривая ухода. |

## Переменные на уровне частей

Область ставит их на каждый `Toast`, пока он показан. Читайте их в своих стилях, но не задавайте.

| Переменная | Назначение |
| --- | --- |
| `--toast-index` | Место тоста в стопке, 0 для самого нового. |
| `--toast-offset` | Сумма высот более новых тостов в px: положение тоста в раскрытом списке без промежутков. |
| `--toast-height` | Высота содержимого тоста в px. |
| `--toast-front-height` | Высота переднего тоста в px; свёрнутая колода принимает высоту переднего тоста. |
| `--toast-swipe-x` / `--toast-swipe-y` | Насколько тост следует за свайпом по своей оси в px, с резиновым сопротивлением в направлении, которое его не закрывает. |
| `--toast-release-duration` | Длительность броска после свайпа, который закрывает тост, по скорости пальца. |

## Взаимодействие состояний и вариантов

- `data-expanded="true"` у области, пока указатель или фокус на тостах, иначе `"false"`.
- `data-placement` у области: `top-start`, `top`, `top-end`, `bottom-start`, `bottom` или `bottom-end`, из пропа `placement`. Внизу колода растёт вверх, тосты появляются снизу, а свайп вниз уводит их за край экрана.
- `data-index` у каждого тоста, то же, что `--toast-index`, и `data-front="true"` у переднего тоста, пока он открыт.
- `data-status="open"`, пока тост показан, и `"closing"`, пока он проигрывает уход.
- `data-swiping="true"`, пока свайп тянет тост, и `data-swipe-direction` (`up`, `down`, `left` или `right`), когда свайп закрыл тост и бросает его.
- `[role='alert']` у тостов, которые вы рендерите как alert, чтобы дать им свой вид.
- `@media (prefers-reduced-motion: reduce)`: части заменяют въезд, масштаб и бросок на проявление.

## Примеры

Передайте `className='notifications'` в `ToastRegion`, чтобы дать тостам больше места вокруг и между ними, сделать углы меньше, подкрасить тосты с `role='alert'` и показать курсор захвата, пока тост тянут:

<!-- example: toast/styling-examples.css -->
```css
.notifications {
  --toast-inset: var(--spacing-12);
  --toast-gap: var(--spacing-6);
  --toast-peek: var(--spacing-8);
  --toast-radius: var(--radius-4);
}

.notifications > [role='alert'] {
  background: color-mix(in oklch, var(--color-error) 10%, var(--surface-primary));
}

.notifications > [data-swiping='true'] {
  cursor: grabbing;
}
```
<!-- /example -->

## Что не переопределять

- Не задавайте `translate`, `scale`, `transition`, `max-block-size`, `overflow` и `clip-path` у `Toast`: они ставят тост в колоду, раскрывают её так, что текст не вылезает, не дают тени тоста лечь на соседей в раскрытом списке, следуют за свайпом и проигрывают уход.
- Не задавайте `position`, `inset`, `display` и `pointer-events` у области: это фиксированная сетка, которая пропускает клики между тостами. Меняйте `placement` или `--toast-inset`.
- Не прячьте тост через `display: none` или `visibility: hidden`: закройте его, чтобы его таймер остановился, а фокус пошёл дальше.
- Не возвращайте тостам `user-select: text`: в WebKit свайп мышью выделял бы их текст.
- Не делайте фон тостов прозрачным без подложки: тосты лежат над страницей и диалогами, и их тексту нужна поверхность, чтобы оставаться читаемым.
