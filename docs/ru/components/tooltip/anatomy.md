# Tooltip: анатомия

## Обзор

`Tooltip` владеет отложенным открытием и координацией всплывающего слоя для короткого несущественного описания. Он намеренно узкий: триггер плюс описательное содержимое и необязательная стрелка для визуальной привязки.

## Обязательные части

### `Tooltip`

Обязательная. Владеет таймингом открытия и координацией триггера с содержимым.

### `TooltipTrigger`

Обязательная. Задаёт цель для наведения или фокуса с клавиатуры. Касание не показывает тултип, а нажатие на триггер скрывает его.

### `TooltipContent`

Обязательная. Рендерит видимое описательное содержимое.

## Необязательные части

### `TooltipArrow`

Необязательная визуальная стрелка, когда всплывающее содержимое должно яснее указывать на триггер.

## Порядок композиции

1. `Tooltip`
2. `TooltipTrigger`
3. `TooltipContent`
4. `TooltipArrow`

## Корректные паттерны композиции

<!-- example: tooltip/minimal-composition.tsx -->
```tsx
import {
  Button,
  Text,
  Tooltip,
  TooltipArrow,
  TooltipContent,
  TooltipTrigger,
} from '@vega-ui/react';

export default function MinimalComposition() {
  return (
    <Tooltip>
      <TooltipTrigger asChild>
        <Button>Publish</Button>
      </TooltipTrigger>
      <TooltipContent>
        <TooltipArrow />
        <Text size={2}>Anyone with the link can view the page</Text>
      </TooltipContent>
    </Tooltip>
  );
}
```
<!-- /example -->

## Некорректные паттерны композиции

### Интерактивные контролы внутри `TooltipContent`

Содержимое тултипа должно оставаться описательным, а не превращаться в мини-поповер.

### Тултип как единственная метка контрола

Триггеру всё равно нужен собственный доступный смысл без тултипа.

### Обязательные инструкции спрятаны только в тултипе

Если содержимое необходимо для выполнения задачи, используйте встроенную справку или другой паттерн оверлея.
