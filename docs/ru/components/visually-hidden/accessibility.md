# VisuallyHidden: доступность

## Подписи

- `VisuallyHidden` особенно полезен для подписей и описаний, предназначенных только для вспомогательных технологий.

## Поведение клавиатуры

- У самого компонента нет поведения клавиатуры.

## Поведение фокуса

- Скрытое содержимое, как правило, не должно получать фокус, если только это не явный и проверенный паттерн.

## Семантика для скринридеров

- Содержимое остаётся в дереве доступности.
- Используйте его, чтобы дополнить видимый интерфейс, а не чтобы заменить весь видимый смысл.

## Семантика в формах

- Полезен для скрытых описаний или имён элементов управления, на которые ссылаются ARIA-атрибуты.

## Риски доступности

- злоупотребление скрытыми подписями вместо улучшения видимой ясности
- рассинхронизация скрытого текста с реальным состоянием интерфейса
