# VisuallyHidden: сравнение

## Быстрое правило выбора

Используйте `VisuallyHidden`, когда содержимое должно оставаться доступным для вспомогательных технологий, но не отображаться визуально. Используйте обычный текст, когда информация должна быть видна всем.

## `VisuallyHidden` или видимый вспомогательный текст

- Используйте `VisuallyHidden` для содержимого, предназначенного только для доступности.
- Используйте видимый вспомогательный текст, когда подсказка полезна всем пользователям.

## `VisuallyHidden` или `aria-label`

- Используйте `VisuallyHidden`, когда нужно реальное содержимое в DOM, на которое можно сослаться или которое можно компоновать.
- Используйте `aria-label` для коротких прямых подписей, когда отдельный узел с содержимым не нужен.

## Выбирайте этот компонент, когда

- содержимое должно оставаться доступным, но не видимым
- полезен скрытый узел с описанием или подписью

## Не выбирайте этот компонент, когда

- информация должна быть видна в обычном интерфейсе
- скрытым текстом пытаются обойти исправление видимого UX
