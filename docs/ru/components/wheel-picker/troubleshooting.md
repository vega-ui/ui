# WheelPicker: решение проблем

## Колесо возвращается после свайпа

### Симптом

Колонка поворачивается к другой опции, а потом обратно к старой.

### Вероятная причина

`value` задан, а родитель не обновляет его в `onChangeValue`.

### Как проверить

- Проверьте, задан ли `value` без обновления состояния в `onChangeValue`.

### Исправление

- Обновляйте состояние в `onChangeValue` или используйте `defaultValue` для неконтролируемой колонки.

## Колонка стоит на недоступной опции

### Симптом

После изменения в другом месте, например переключения на февраль, колонка дней показывает приглушённое 31-е.

### Вероятная причина

Родитель держит значение, которое стало недоступным. Колонка уходит с недоступной опции после прокрутки, но не меняет значение, выбранное родителем.

### Как проверить

- Сравните контролируемое `value` с опциями `disabled` после изменения.

### Исправление

- Ограничивайте значение в родителе, когда меняются опции, например день — длиной месяца.

## `onChangeValue` не вызывается, пока колесо крутится

### Симптом

Значение обновляется только когда колесо останавливается.

### Вероятная причина

Так задумано: колонка сообщает опцию, на которой остановилась прокрутка, а не каждую строку, мимо которой она прошла.

### Как проверить

- Поверните колонку через ArrowUp: значение обновится сразу.

### Исправление

- Показывайте значение из `onChangeValue`; для предпросмотра, пока колесо крутится, используйте остановленное значение, потому что строки между ними не выбраны.

## Поиск по набору не находит опцию

### Симптом

Набор начала опции её не выбирает.

### Вероятная причина

Опция показывает иконку или компонент без текста, поэтому набор сравнивается с её сырым `value`, а не с тем, что видит пользователь.

### Как проверить

- Проверьте `aria-valuetext` колонки на этой опции: в нём сырой `value`.

### Исправление

- Дайте опции `label` с её текстом.
