# Семейства компонентов

Этот раздел группирует компоненты VegaUI по областям продуктовых решений, а не по именам экспортов. Обращайтесь к этим страницам, когда первый вопрос — «какой элемент управления или паттерн мне нужен?», а не «как использовать компонент X?».

- [Ввод дат](./date-inputs.md)
- [Текстовый ввод](./text-inputs.md)

- [Примитивы раскладки](./layout-primitives.md)
- [Статусы и обратная связь](./status-feedback.md)

## Как пользоваться этим разделом

- Начинайте здесь, когда несколько компонентов выглядят похоже, но решают разные UX-задачи.
- За окончательными деталями API, анатомии, доступности и решения проблем переходите на страницы компонентов по ссылкам.
- Воспринимайте документы о семействах как помощь в навигации и выборе, а не как замену документации отдельных компонентов.
