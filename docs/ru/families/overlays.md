# Оверлеи

Используйте эту страницу, когда содержимое открывается поверх текущей страницы и главный выбор касается степени прерывания, поведения привязки и формы панели.

## Быстрые правила выбора

- Используйте [Tooltip](../components/tooltip/) для коротких неинтерактивных подсказок.
- Используйте [Popover](../components/popover/) для короткого привязанного немодального содержимого.
- Используйте [Dialog](../components/dialog/) для сфокусированных модальных задач.
- Используйте [Drawer](../components/drawer/) для сценариев в боковой панели, сохраняющих контекст страницы.
- Используйте [Sheet](../components/sheet/) для удобных для касаний панелей или поведения нижней шторки.

## По силе взаимодействия

- Только подсказка: [Tooltip](../components/tooltip/)
- Лёгкое контекстное содержимое: [Popover](../components/popover/)
- Сильное модальное прерывание: [Dialog](../components/dialog/)
- Боковой сценарий с сохранением контекста: [Drawer](../components/drawer/)
- Выдвижная панель с приоритетом мобильных устройств: [Sheet](../components/sheet/)

## Частые ошибки классификации

- Не используйте [Popover](../components/popover/) для модальных или деструктивных сценариев.
- Не используйте [Dialog](../components/dialog/), когда содержимое на самом деле ведёт себя как боковая панель или нижняя шторка.
- Не используйте [Tooltip](../components/tooltip/) для интерактивного содержимого.
- Не используйте [Drawer](../components/drawer/), когда задача должна ощущаться центрированной и ограниченной.
- Не используйте [Sheet](../components/sheet/), если точки привязки (snap points) или поведение выдвижной панели не являются частью UX.

## С чего начать

- Быстрые контекстные действия: [Popover](../components/popover/)
- Подтверждения и сфокусированные формы: [Dialog](../components/dialog/)
- Фильтры, инспекторы, панели участников: [Drawer](../components/drawer/)
- Оформление заказа или мобильные панели действий: [Sheet](../components/sheet/)
- Дополнительные подсказки: [Tooltip](../components/tooltip/)
