# @vega-ui/i18n

Locale, calendar system and phone number support for `@vega-ui/react`: the `CalendarSystem` adapter contract, the default Gregorian calendar, any other calendar of `Intl` through `createCalendarSystem`, calendar-aware date operations on ISO `YYYY-MM-DD` strings, locale helpers, `Intl` formatting, and the `PhoneNumbering` adapter contract for phone numbers with the default `phoneNumbering` on libphonenumber-js. No knowledge of the components.
