# Component Validation Surfaces

Check these before accepting a theme:

- `Button`
- `TextField`
- `Select`
- `Checkbox`
- `Radio`
- `Dialog`
- `Drawer`
- `Sheet`
- `Popover`
- `Tooltip`
- `Card`
- `Table`

If the product uses advanced picker flows, also validate:

- `Calendar`
- `DateField`
- `DateRangeField`
- `DateTimeField`
